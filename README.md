# 寂响遗迹 / Echoes Below

Unity 2D 俯视角像素风肉鸽射击原型。以可视声波惊醒有限敌人，用附近清醒敌人的数量换取有上限的伤害加成；在 5×5 随机房间格中探索三层地牢，击杀升级，自选时机挑战守关者。

## 运行

1. 用 Unity Hub 添加本目录，使用 **2022.3.62f3c1** 打开。
2. 打开 `Assets/Echoes/Scenes/Prototype.unity`，点击 Play。
3. 若场景尚未生成，执行编辑器菜单 **Echoes > Create or Update Prototype Scene**。
4. 如需 Windows 程序，执行 **Echoes > Build Windows Prototype**，输出到 `Builds/Windows/EchoesBelow.exe`。

最新改动请在 Unity 中运行入口场景体验，默认不重新生成 EXE。此前的 Windows 试玩版对应初版，运行时保留同目录的数据文件夹和 DLL。初版验证见 `Docs/008-自动验证与原型交付.md`，自动瞄准、黑暗视野和升级暂停改动见 `Docs/009–011`。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 普通射击 | 按住左键，自动瞄准可见的最近敌人；无目标时使用鼠标方向 |
| 投掷响铃诱饵 | Q，朝鼠标方向 |
| 激活守关者 | 进入本层 Boss 房，靠近祭坛按 E |
| 选择升级 | 点击卡片或 1 / 2 / 3 |
| 下潜 | 本层 Boss 击败后按 E 或点击按钮 |
| 暂停 / 静音 | Esc / M |

起点没有敌人。静止时主视野为零，仅保留身边渐变视野；连续走路 0.2 秒后开始每 0.5 秒在当前位置留下视野圈，开枪也会生成圈。圈先快后慢扩张，在最大值停留 0.5 秒，再先慢后快收缩，圈心始终固定，外侧带有固定宽度渐变。普通怪先调查声源，接近到步行总视野范围才追踪玩家。沿开着的门探索，普通房间不会锁门。灰色横线为沉睡，金色标记为调查或警戒，红色竖线为追击。关闭音效仍可完成游戏。经验满后保持满条并暂停，选定升级后恢复。

每层是一张 5×5 房间格地图：房间格 36×36，整图 180×180；起始房在顶排中央，Boss 房在底排中央，只从北侧开一个门；中间由 1×1、1×2、1×3、2×2 与 L 形大房间随机铺满，并使用 donut、柱厅、货箱 S 路、断角、长厅、庭院、L 转角等 P0 布局。三层的主题依次为静钟街区、锈鸣工坊、原音圣所。Boss 击败后进入下一层，第三层 Boss 击败才通关。相机参考分辨率为 640×360，大房间仍会跨屏。

## 审查与调参

第一层已接入 13 类原生房间美术（含纵向长椅共 14 张 PNG）：钟架、维修货箱、候车椅、断柱、碎石、主题贴花、壁灯、门结构与 Boss 柱；修复了图片缩放重复扩大碰撞的问题。P1 唯一制作清单和朝向规则见 `Docs/034`，接入、验证与截图见 `Docs/035`。第二、三层主题大件仍是 P0。

初始渐变宽度为 3。脚步会在每次步行圈生成时发出实际声音，惊醒步行主圈内的敌人；渐变带只提供视野。修改与验证记录见 `Docs/019`、`Docs/020`。房间生成与三层地牢的规则、配置和验收记录见 `Docs/032-房间生成与三层地牢.md`；障碍/装饰扩展方案与参考布局见 `Docs/033-房间障碍与装饰扩展报告.md`；可直接交付美术制作的尺寸/碰撞/导入清单见 `Docs/034-房间生成美术需求清单.md`。

- `Assets/Echoes/Settings/DefaultGameConfig.asset`：集中配置战斗、成长、房间生成、每层敌人数量和楼层强度。
- `Assets/Echoes/Scripts/Core/`：整局流程、纯规则、升级定义、商店。
- `Assets/Echoes/Scripts/Combat/`：玩家、敌人状态、子弹、声波、诱饵。
- `Assets/Echoes/Scripts/World/`：房间布局生成、`RoomLayouts` 布局原型、Tilemap 地图、寻路、主题美术、相机。
- `Assets/Echoes/Scripts/UI/`：HUD、5×5 小地图、三选一、商店、暂停与层间结算。
- `Docs/001-…` 起：逐项功能记录，包含编辑器设置与验证方法。

## 测试

在 **Window > General > Test Runner** 运行 EditMode 的 `Echoes.Tests` 和 PlayMode 的 `Echoes.PlayModeTests`。当前自动化验收为 EditMode 29/29、PlayMode 38/38：覆盖 300+ 种子的房间铺满/旋转/连通/叶子门规则、回退布局、6 个种子的 180×180 实际场景连通、房间实心密度、5×5 小地图、门/Boss/视野、商店、正式美术、敌人近战/远程分工、三层切换与最终胜利。生成截图与详细结果见 `Docs/032`，临时截图写入 `TestResults/`。

## 当前范围

三层随机地牢，每层约 10–25 个房间、约 139 只普通怪和一只 Boss；包含金币商店、六槽多武器、被动道具、响铃诱饵与六种可重复升级。P0 布局使用现有 16 种道具，第一层中间房实心覆盖率约 6.7–10.2%；P1 的大件/贴花/墙饰清单见 `Docs/033`。尚未实现 Fairy/Blood/Puzzle/Trap 特殊房、钥匙锁门、正式音乐或完整平衡校准；敌人密度与楼层强度仍是初调值，需完整人工试玩后调参。中文字体使用 Noto Sans SC，字体目录内包含 OFL 许可证。
