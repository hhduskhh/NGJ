# 寂响遗迹 / Echoes Below

Unity 2D 俯视角像素风肉鸽射击原型。以可视声波惊醒有限敌人，用附近清醒敌人的数量换取有上限的伤害加成；在 5×5 随机房间格中探索三层地牢，击杀升级，自选时机挑战守关者。

## 运行

1. 用 Unity Hub 添加本目录，使用 **2022.3.62f3c1** 打开。
2. 打开 `Assets/Echoes/Scenes/Opening.unity`，点击 Play。片头播完进入第一层，空格或 Esc 跳过。直接调试战斗时打开 `Assets/Echoes/Scenes/Prototype.unity`。
3. 若场景尚未生成，执行编辑器菜单 **Echoes > Create or Update Prototype Scene**。
4. 如需 Windows 程序，执行 **Echoes > Build Windows Prototype**，输出到 `Builds/Windows/EchoesBelow.exe`。

最新改动请在 Unity 中运行入口场景体验，默认不重新生成 EXE。此前的 Windows 试玩版对应初版，运行时保留同目录的数据文件夹和 DLL。初版验证见 `Docs/008-自动验证与原型交付.md`，自动瞄准、黑暗视野和升级暂停改动见 `Docs/009–011`。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 普通射击 | 按住左键，自动瞄准可见的最近敌人；无目标时使用鼠标方向 |
| 投掷响铃诱饵 | Q，朝鼠标方向 |
| 激活守关者 | 进入本层 Boss 房，靠近祭坛按 E |
| 选择升级 | 点击卡片或 1 / 2 / 3 |
| 下潜 | 本层 Boss 击败后按 E 或点击按钮 |
| 暂停 / 静音 | Esc / M |

起点没有敌人。静止时主视野为零，仅保留身边渐变视野；连续走路 0.2 秒后开始每 0.5 秒在当前位置留下视野圈，开枪也会生成圈。圈先快后慢扩张，在最大值停留 0.5 秒，再先慢后快收缩，圈心始终固定，外侧带有固定宽度渐变。普通怪先调查声源，接近到步行总视野范围才追踪玩家。沿开着的门探索，普通房间不会锁门。灰色横线为沉睡，金色标记为调查或警戒，红色竖线为追击。关闭音效仍可完成游戏。经验满后保持满条并暂停，选定升级后恢复。

每层是一张 5×5 房间格地图：房间格 36×36，整图 180×180；起始房在顶排中央，Boss 房在其余四排随机出现，起始房和 Boss 房各保留一个门；中间由 1×1、1×2、1×3、2×2 与 L 形大房间随机铺满，并采用图纸隔墙、陷阱和原生家具布局。三层的主题依次为静钟街区、锈鸣工坊、原音圣所。Boss 击败后进入下一层，第三层 Boss 击败才通关。相机参考分辨率为 640×360，大房间仍会跨屏。

## 审查与调参

三层 P1 房间美术均已接入，合计 33 类、36 张原生 PNG。第三层以选定 imagegen B 图音叉神龛为基准，补齐晶簇、陶壳、管风琴、封存匣、三种贴花、壁架与 Boss 柱，碰撞按实际脚底配置；共用门和摊位继续复用。P1 清单与朝向规则见 `Docs/034`，三层接入与截图分别见 `Docs/035`、`Docs/037`、`Docs/043`。

初始渐变宽度为 3。脚步会在每次步行圈生成时发出实际声音，惊醒步行主圈内的敌人；渐变带只提供视野。修改与验证记录见 `Docs/019`、`Docs/020`。房间生成基线见 `Docs/032-房间生成与三层地牢.md`；三层原生美术清单见 `Docs/034-房间生成美术需求清单.md`；当前房间示意图见 `Docs/062-当前房间示意图.md`；世界观与 UI 氛围基调见 `Docs/063-世界观故事与UI氛围基调.md`；图纸动线规则见 `Docs/064-房间动线重制.md`；合并后的 P0 修复与最新验收见 `Docs/065-合并P0稳定性收口.md`。

- `Assets/Echoes/Settings/DefaultGameConfig.asset`：集中配置战斗、成长、房间生成、每层敌人数量和楼层强度。
- `Assets/Echoes/Scripts/Core/`：整局流程、纯规则、升级定义、商店。
- `Assets/Echoes/Scripts/Combat/`：玩家、敌人状态、子弹、声波、诱饵。
- `Assets/Echoes/Scripts/World/`：房间布局生成、`RoomLayouts` 布局原型、Tilemap 地图、寻路、主题美术、相机。
- `Assets/Echoes/Scripts/UI/`：HUD、5×5 小地图、三选一、商店、暂停与层间结算。
- `Docs/001-…` 起：逐项功能记录，包含编辑器设置与验证方法。

## 测试

在 **Window > General > Test Runner** 运行 EditMode 的 `Echoes.Tests` 和 PlayMode 的 `Echoes.PlayModeTests`。测试覆盖 300 个种子的房间规则、6 个种子的实际场景连通、低帧率门口追击、三层陷阱落点与净空、菱形禁刷区、视野、商店、多武器、三层切换、最终胜利及开场 CG。最新结果见 `Docs/065-合并P0稳定性收口.md`；`Docs/032` 的数字保留为历史基线。示意图导出测试为 Explicit，需单独运行；临时日志和截图写入 `TestResults/`。

## 当前范围

三层随机地牢，每层约 10–25 个房间；普通怪按每房间格 7 只、单房 6–32 只配置，另有一只 Boss。包含金币商店、六槽多武器、被动道具、响铃诱饵、八种可重复升级、图纸隔墙、地刺和感应炸弹。三层均使用 P1 原生房间美术，字体使用 Fusion Pixel 简中点阵字体。第一层已有 EmptyCity 探索配乐；尚未实现独立特殊房流程、钥匙锁门、第二三层正式配乐或完整平衡校准；敌人密度与楼层强度仍需完整人工试玩后调参。
