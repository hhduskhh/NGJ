# 普通怪惊醒与拖步声

普通近战怪和射手醒来后，每实际移动 2.4 个世界单位，播放一次原创合成的短拖步声。玩家可以从左右声像和距离衰减听出接近的方向。停住时停止触发。惊醒仍使用已有的擦地声，多只同时惊醒会合并。拖步只播放音频，附近怪物与视野系统不会收到声音事件。

## 相关文件

- `Assets/Echoes/Resources/CombatAudio/EnemyStep.wav` 为两种普通怪共用的单声道短音效。
- `Assets/Echoes/Scripts/Combat/EnemyController.cs` 按刚体位置累计步距。`NoiseSystem.cs` 负责世界音效播放，拖步最多占三个声道。
- `Assets/Echoes/Scripts/Core/GameConfig.cs` 定义参数。编辑器内选择 `Assets/Echoes/Settings/DefaultGameConfig.asset`，在 Combat audio 分组调整。

| 参数 | 初始值 | 作用 |
| --- | --- | --- |
| Wake Volume | 0.14 | 闻声惊醒时第一下擦地的音量 |
| Enemy Step Volume | 0.07 | 随后移动时的拖步音量 |
| Enemy Step Distance | 2.4 | 每次拖步间隔的实际移动距离，增大后更稀疏 |

## 验证与已知问题

Unity CLI 运行 PlayMode 的 `Echoes.Tests.CombatAudioTests`，两项通过。覆盖资源加载、位移不足时静音、累计超过步距后按方向发声、静止后停止触发，以及附近沉睡怪和视野保持原状。

在 Prototype 场景选一个侧门，向避开怪物的方向开一枪，听门后的惊醒声。换位并停火，听拖步是否来自怪物靠近的一侧。再连续开火后停手，对比两种情况下的可辨度。首版响度与步距仍待耳机及扬声器实机试听；左右声像不能区分正前与正后。
