# 074 分层商店与守关者血条

第一层在普通房间中随机放置一个商店。第二、三层各自在出生房内选择柜台位置，给出生点和出口路牌留出空间。玩家走到柜台前按 E 即可购物。

换层时先重置守关者的唤醒状态。顶部血条和名称仅在本层守关者已唤醒且存活时显示。

## 相关文件与编辑器配置

- `DungeonMap.cs` 按楼层筛选候选房间，并检查柜台可达性与房间连通性。
- `RunController.cs` 重置楼层状态，`GameHud.cs` 控制血条和名称的可见性。
- 使用现有场景、商店和 HUD，无需修改 Inspector。

## 验证

`FloorGenerationTests` 的多种子用例检查三层商店所属房间和到达柜台的路径。三层通关用例检查血条在唤醒后出现、换层后隐藏。编辑器内可用 `StartStallTests` 复验实际键盘进店和退出。

Unity 2022.3.62f3c1 的两项 PlayMode 测试均通过。地图验证使用种子 100 至 105。此次为无图形验证，未进行键盘试玩。
