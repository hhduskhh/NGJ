# 八项升级与幸运掉落

经验满后从八张卡中随机展示三张不同的卡。选中的属性在本局后续楼层继续生效。

| 升级 | 每次选择的效果 |
| --- | --- |
| 精密弹头 | 公共基础伤害 +20% |
| 快装枪机 | 各武器射击间隔乘 0.88，最短 0.05 秒 |
| 轻装行进 | 公共移速加成 +12% |
| 应急修复 | 生命上限 +20，随后恢复 35 点生命 |
| 共振扩音器 | 公共枪声半径 +5，每只围攻怪物的增伤提高 1 个百分点 |
| 诱饵调校 | 下次及后续投掷的冷却缩短 2 秒，最短 4 秒 |
| 致命打击 | 暴击伤害倍率增加 8 个百分点，初始 200% 升至 208% |
| 幸运四叶草 | 当局掉落翻倍概率增加 8 个百分点，最高 100% |

普通怪死亡时用当前幸运独立判定一次。触发时该枚金币的面值翻倍，拾取后一次到账。经验照常结算。沿用公共枪声半径上限 12 和每只近敌增伤上限 20%，武器噪声系数作用于公共半径之后。

## 相关文件与编辑器配置

八张卡的名称和效果在 `UpgradeDefinition.cs`，角色属性、射击间隔和掉落分别在 `PlayerController.cs`、`WeaponInventory.cs`、`RunController.cs`。商店属性区显示幸运概率与两位小数的暴击倍率。

两张透明 32×32 图标位于 `Assets/Echoes/Art/UI/Upgrades/`，使用 Point 采样。资源 `Assets/Echoes/Resources/PresentationArt.asset` 已绑定红宝石准星和四叶草，场景无需另行配置。

## 验证方法与已知限制

在 PlayMode 中运行 `EightUpgradesApplyToCombatAndLoot`，检查八张卡的图标、暴击倍率、围攻收益、射击与诱饵冷却下限，以及满幸运时的双倍金币和单份经验。`LootPausePurchaseRefreshAndReopen` 覆盖零幸运下的普通掉落。

当前普通怪的掉落实体只有金币。累计加成达到上限后，同名卡仍遵循现有抽取规则。
