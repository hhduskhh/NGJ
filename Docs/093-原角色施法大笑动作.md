# 093 原角色施法大笑动作

按 F 成功释放全屏点亮时，主角跟随四秒笑声仰头、抖肩、弯腰捧腹，再回到常态。施法只切换显示帧，沿用主角的朝向、脚底位置及移动和射击输入。

## 素材与编辑器配置

`Assets/Echoes/Resources/Art/Common/hero.png` 的待机首帧是此次动画的像素来源。`heroLaugh.png` 的起始姿势逐像素对应待机帧，其余七个姿势通过转动头部、倾斜躯干、收起手臂得到。脸部、服饰、装备和颜色都取自原精灵。动作节奏参考[奶龙大笑【原版】](https://www.bilibili.com/video/BV1p2Tp6REay/)。

`ProductionArtImporter.cs` 将精灵表切成两行四列，每帧 32 × 32，16 PPU，沿用原主角的脚底轴心和 Point 过滤。`DungeonVisibility.TryLightScreen` 在释放成功时启动 `CharacterArt.PlayCastLaugh`。动画按游戏时间播放，暂停时定格。

## 验证

在 Prototype 场景按 F，观察笑声前半段的仰头动作和后半段的弯腰动作。PlayMode 用例 `ScreenLightRevealsViewportAndRechargesInPlayTime` 检查实际加载的精灵、尺寸、轴心、动作阶段及四秒后恢复常态。手动调节音量时，动作仍按同一节拍播放。
