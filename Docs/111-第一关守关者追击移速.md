# 第一关守关者追击移速

第一关 Boss 的普通追击速度由每秒 2.55 个世界单位调为 2.0。第二、三关的普通追击速度为 2.55。

在 `Assets/Echoes/Settings/DefaultGameConfig.asset` 的 Gatekeeper 区域调整 `firstFloorBossSpeed`。`GameConfig.cs` 声明其默认值，`EnemyController.Move` 按楼层选择追击速度。

在 PlayMode 运行 `EnemyRoleTests.BossUsesFloorHealthAndAttackPatterns`，逐关检查首次攻击前的刚体追击速度。该值为开阔路段的速度，抵达寻路节点或遇到障碍时，实际速度可降低。
