# 040 游戏界面重构

## 界面

- 战斗开局移除按键提示。交互提示移到下方，顶部留给守关者生命。跨层清除上一层的守关者血条。
- 暂停页左侧列操作，右侧列房间与战斗信息。设置页显示本次探索的调试开关。
- 升级页按行展示快捷键、道具图标、名称和效果，每行都能点击。商店把商品图标与名称放在一起，刷新概率随货架显示。仅有一页被动道具时隐藏翻页按钮。
- 楼层完成、胜利和失败共用探险记录布局，根据状态显示恢复量、所在房间或通关结果。

## 文件与编辑器配置

运行时布局在 `Assets/Echoes/Scripts/UI/GameHud.cs`、`GameHud.Screens.cs` 和 `GameHud.Shop.cs`。CanvasScaler 使用 1600 × 900 参考画布和 Expand 模式。继续使用原有角色、物品、按钮与商店贴图，无需在编辑器重新绑定素材。

## 验证与截图

在独立 Unity 副本运行 PlayMode。验证游戏推进、升级选择、商店交易与满装备合成、被动道具翻页、调试模式开关，并在运行时切换到暂停及三种结算状态检查显示。满装备测试的角色先站到实际柜台，再触发商店交互。五项项目测试和一项截图检查最终均通过。
