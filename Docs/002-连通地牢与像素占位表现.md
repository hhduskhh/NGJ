# 002-连通地牢与像素占位表现

- 功能：固定七房间单层地图，普通房间永久开门；所有相邻房间连通。格子碰撞和广度优先寻路共用同一份可通行数据，敌人可以跨房间移动。显示房间名与探索小地图。
- 相关文件：`DungeonMap.cs`、`PixelArt.cs`、`CameraFollow.cs`、`Prototype.unity`。
- 编辑器配置：16 PPU、480×270 参考分辨率、Point 纹理过滤、无抗锯齿；使用项目实际 URP 14 中的 `UnityEngine.Experimental.Rendering.Universal.PixelPerfectCamera`。HUD 使用屏幕叠加 Canvas。
- 验证方法：从起点前往小地图右上角守关房；途中门口不锁闭；Play Mode 集成测试检查七房间全部可达。
- 已知问题：地图固定，不包含程序化随机生成；墙壁与地板为代码生成的 16×16 占位像素图，尚未进行正式美术制作。相机不会钳制到单个房间，因此能观察相邻空间。
