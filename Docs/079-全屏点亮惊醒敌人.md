# 079 全屏点亮惊醒敌人

按 F 成功释放时，镜头内沉睡的普通敌人同时惊醒，包括墙后的近战怪和远程守卫。敌人开始调查玩家释放技能时所在的位置。判定只发生一次，随后才进入画面的敌人仍按平时的听觉规则行动。守关者继续由祭坛激活。

## 实现与编辑器配置

`Assets/Echoes/Scripts/World/DungeonVisibility.cs` 在 `TryLightScreen` 中按敌人的世界坐标检查相机视口，再调用 `EnemyController.Hear`。范围随相机画面变化，无需为场景配置触发器或听觉半径。静音只影响音频播放。

## 验证与已知限制

在 Unity Test Runner 的 PlayMode 中运行 `AutoAimVisibilityTests.ScreenLightWakesSleepersInTheViewportAtCastTime`。用例将普通敌人放在屏内墙后，验证其调查目标，同时检查屏外敌人、祭坛守关者，以及冷却中重复释放。屏幕边缘按敌人根节点的位置判断。
