# 武器二合一

在商店中，选择两把同款、同品质的已装备武器进行合成，得到一把高一档品质的同款武器，并空出一个武器槽。红Ⅳ为最高品质。

货架的“买入合成”使用一把在售武器和一把已装备的同款同品质武器，按货架价格扣款。满栏时也可使用。普通购买和手动合成仍可分别选择。

合成规则在 WeaponInventory.cs，交易在 ShopController.cs，按钮在 GameHud.Shop.cs。沿用现有四档武器配置，无需重新配置编辑器。运行 ShopTests 中 OnlyTwoMatchingWeaponsCanCombine、PurchaseSuppliesTheSecondCopyEvenAtCapacity 和 FullSlotsMergeSaleAndFloorReset 验证数量、匹配条件、品质上限、扣款和冷却。
