## 素材与编辑器配置

对应图集在 `Assets/Echoes/Resources/Art/Floor2/` 和 `Floor3/`。每类敌人的六个姿态共用一张图集，沿用已有 Unity 导入设置。进关时由 `DungeonMap.Generate` 设置楼层。生成敌人时，`EnemyController.Create` 将同一类型交给初始精灵绑定与角色动画，`GameArt` 从当前楼层目录取图。场景无需手动绑定。

## 验证与已知限制

在 Unity Test Runner 的 PlayMode 中运行 `EnemyRoleTests.RolesMatchFloorArtAndWalkerCanBeOutrun`。测试通过正式换层入口逐层生成敌人，将每只沉睡敌人的实际精灵与该层对应图集的第 0 帧比较，并在刷新外观后再次比较。

各层的 `elite.png` 是预留素材；当前关卡只生成表中三类敌人。
