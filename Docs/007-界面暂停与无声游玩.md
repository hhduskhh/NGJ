# 007-界面暂停与无声游玩

- 功能：uGUI + TextMeshPro 中文 HUD，显示生命、经验、等级、围攻加成、枪声范围、诱饵冷却、地图、计时与击杀数。Esc 暂停和继续，M 静音。升级、胜利、失败使用独立面板，结算后可重新开始。
- 相关文件：`GameHud.cs`、`RunController.cs`、`RuntimeSmokeTests.cs`。
- 编辑器配置：Canvas 为 Screen Space Overlay，1600×900 参考尺寸，具备 GraphicRaycaster 与 EventSystem。使用随工程提供的 Noto Sans SC 中文字体与 TMP 动态图集，许可保留在 `Assets/Echoes/Fonts/OFL.txt`。
- 验证方法：关闭声音完成调查、追击、诱饵与守关战；检查升级键盘与鼠标选择；暂停时敌人、声波、投射物与冷却停止；重新开始恢复正常时间流速。
- 已知问题：当前重点验证 16:9 桌面窗口，超宽屏与小分辨率还需单独适配。首次出现新字形时 TMP 动态图集会产生少量开销。

系统动态字体在 Unity 2022 / TMP 3.0.7 的实际运行中加载失败，已改为随工程提供的字体资产。
