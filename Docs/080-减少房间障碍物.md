# 080 减少房间障碍物

三层普通房间减少重复摆放的实心家具。第一层减少长椅、立柱与杂物，第二层将传送带和管道移向角落，第三层减少成组的晶簇与圣龛。生成器不再为了凑足掩体而向剩余空地补放家具。

## 文件与编辑器配置

家具候选位置在 `RoomLayouts.cs` 和 `RoomLayouts.ThirdFloor.cs` 中定义。`DungeonMap.cs` 按房间单元统计成功放置的家具，并检查房间连通性。在 Inspector 选中 `Assets/Echoes/Settings/DefaultGameConfig.asset`，可调整 `Max Furniture Per Cell`，默认每个普通房间单元最多 5 件，与 `GameConfig.cs` 的默认值一致。商店柜台单独生成。

## 验证

Unity Test Runner 的 PlayMode 测试中，`FloorGenerationTests.ManySeedsProduceConnectedWalkableFloors` 检查多种子三层地图的房间可达性及家具数量。`RoomPropPhysicsTests` 检查家具碰撞与可行走格的一致性。

默认种子下统计各层所有普通房间。宽敞地格指以该格为中心的 3×3 范围全部可走。

| 楼层 | 实心物件（调整前 → 后） | 宽敞地格占比（调整前 → 后） |
| --- | ---: | ---: |
| 第一层 | 274 → 78 | 63% → 76% |
| 第二层 | 370 → 83 | 54% → 73% |
| 第三层 | 526 → 95 | 53% → 76% |

## 已知限制

家具数量随地图种子和房型变化。室内隔墙仍按房型图纸生成，部分门口和转角仍需绕行。
