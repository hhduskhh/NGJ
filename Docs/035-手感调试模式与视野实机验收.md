# 035-手感调试模式与视野实机验收

- 功能：按 `Esc` 暂停，点击「设置」，可切换「手感调试模式」。默认关闭；开启后 HUD 和商店显示「金币 无限」，购买、购买合成及刷新免除金币限制并且不扣余额。库存售罄、武器槽位、被动持有上限等规则保持原有逻辑。
- 关闭与重开：关闭后恢复已有金币和正常扣费，调试期间拾取或出售获得的金币照常保留。本次探险跨层保留开关，重新开始默认关闭。
- 相关文件：`RunController.cs`、`ShopController.cs`、`GameHud.cs`、`GameHud.Shop.cs`、`FeelDebugModeTests.cs`、`GameplayVisionCaptureTests.cs`。
- 编辑器配置：无需调整场景、预制体或配置资产。设置界面沿用现有 uGUI Canvas 与暂停菜单样式。
- 视野验收：使用真实 `Prototype` 场景、正式墙地和障碍物美术、角色、HUD 及游戏相机，在门洞、墙角和内部障碍旁实际射击；等待视野圈展开并断言帧数和游戏时间推进后截图，保留正常视野半径和渐变配置。
- 验证结果：独立副本 PlayMode 9/9 通过，涵盖设置按钮启用和关闭、零金币购买、连续三次刷新、正常金币收益保留、关闭后恢复扣费、重新开始默认关闭及既有商店回归；截图前断言游戏时间和帧数推进。已逐张检查实际门洞、墙角和障碍物截图，未见此前重复的墙格锯齿或三角形黑缺口，遮挡区域仍保持黑暗。
- 验证版本：当前已提交版本 `86a0778` 加本轮调试模式；工作区正在接入的房间 P1 素材尚缺门槛资源，独立副本用于保留这些未提交改动并完成实际关卡验证。
