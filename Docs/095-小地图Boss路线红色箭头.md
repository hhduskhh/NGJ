# 095 小地图 Boss 路线红色箭头

小地图用亮红色标出从当前房间前往 Boss 房的最短路线上的第一扇未探索门。普通探索方向为金色，两侧均已探索的门为灰色短线。路线按经过的门数计算，有多条等长路线时选一条。

## 相关文件与编辑器配置

- `DungeonMap.cs` 根据本层实际门洞，从 Boss 房反向搜索各房间的下一站。
- `GameHud.cs` 在小地图重绘时选择路线门，并为门洞和箭头着色。
- `GameConfig.cs` 提供颜色默认值。在 DefaultGameConfig 的 Minimap 分组中调整 Minimap Boss Route Door 即可更改红色。

## 验证与已知限制

Unity 2022.3 的两项 Minimap PlayMode 测试通过，覆盖出生房红色箭头、过门后的灰色门标、地图揭示及玩家位置。可在 Prototype 场景进入岔路，观察红色箭头是否指向 Boss 路线上下一扇未探索门。实际屏幕上的辨识度尚未人工试玩确认。
