# 远程命中与受击追踪

敌人的脚底圆形碰撞体负责移动，额外的触发区域随当前动画帧和朝向更新，覆盖可见身体。子弹命中身体或脚部时结算伤害，同一发穿透弹只对每个敌人结算一次。

存活的受击敌人会立即追踪玩家当前位置。在重新进入正常侦测范围前，其他声音不会打断追踪。进入侦测范围后恢复原有追击和丢失目标规则。未召唤的 Boss 仍由入口开关激活。

相关代码为 `EnemyController`、`CharacterArt` 和 `Projectile`。受击区域使用 Unity 导入精灵时生成的物理轮廓，无需手工配置。运行 RuntimeSmokeTests 的 DistantTorsoHitDealsDamageAndTracksMovingPlayer，从 20 格外发射实弹，检查上半身命中扣血、苏醒以及玩家移动后的追踪。
