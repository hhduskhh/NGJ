# 商店被动道具图标

12 件道具按商店顺序交付，位置为 [美术交付目录](../美术/商店被动道具图标-12件/)。其中「图标」包含 32×32 透明 PNG，「原始图集」包含三张云端原图。对照预览同时展示原尺寸和三倍像素视图。

## 编辑器配置

在 Comfy Cloud 打开交付目录中的「商店被动道具图集.json」。默认参数为 A 组，B、C 组的完整提示词和固定 seed 见同目录的「生成与额度记录.md」。品质由游戏卡框表达，本次仅交付美术文件。

## 验证与已知差异

三组均使用 Z-Image Turbo，各完成一次单张图集运行。导出的工作流已在云端重新打开。12 张图标已核对尺寸、硬透明和边距，并在深色底检查了枪机、套管、单喇叭和三喇叭的辨识度，以及线圈和音叉的透底。原图有洋红背景，最终 PNG 已去底。弹头、搭扣、维修箱和音叉含本地像素修整，工作流复现的是裁切前的图集。
