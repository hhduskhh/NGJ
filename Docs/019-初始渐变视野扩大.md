# 019-初始渐变视野扩大

- 功能：初始渐变视野宽度由 1.5 增大为 3；静止主视野仍为 0，步行和声波圈外沿用同一固定渐变宽度。
- 相关文件：`GameConfig.cs`、`DefaultGameConfig.asset`、`HearingAndVisionPulseTests.cs`。
- 编辑器配置：配置资产中的 `gradientVisionRange=3`；新建配置资产的默认值同步更新。
- 验证方法：静止时中心至黑暗边界的渐变范围翻倍；主圈外的渐变带同样变宽。针对性测试检查默认宽度与渐变中点覆盖度。
- 已知问题：怪物发现距离按既有规则绑定步行总视野，因此默认从 `3+1.5=4.5` 同步变为 `3+3=6`；脚步实际惊醒半径仍为主圈半径 3。

本轮定向测试已通过，确认实际加载配置的渐变宽度为 3，静止渐变中点覆盖度与边界范围正确。
