# 三层共用背景音乐

《EmptyCity》从静钟街区开始循环，进入锈鸣工坊和原音圣所时沿用同一音源，音乐从当前位置继续播放。本次更新取代 061 中的楼层限制。

播放逻辑位于 `Assets/Echoes/Scripts/Core/RunController.cs`。三层共用 Prototype 场景中 RunController 的 Music Volume，默认值为 0.12。M 键同时控制音乐与音效。

运行 PlayMode 测试 `CombatAudioTests.EmptyCityLoopsAcrossAllFloors` 可检查两次下潜后同一音源仍在播放。各层战斗音效与音乐的相对响度仍待人工试听。
