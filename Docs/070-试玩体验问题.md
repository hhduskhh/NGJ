# 070 寂响遗迹试玩体验报告

体验日期为 2026-11-14。版本为 `fb30094` 对应工作区的独立副本，Unity 2022.3.62f3c1，默认种子 713。重点修复顺序建议为自动索敌、首次入场引导、升级零收益、重开重复。以下的秒数均为游戏内时间。

## 试玩经过

| 路线 | 操作与结果 |
| --- | --- |
| 正式入口 | 播完片头，经过标题、设置、返回、开始游戏进入第一层。首层生成 14 个房间、161 只普通敌人和 1 只守关者。 |
| 普通开局，两种打法 | 一次走到摊位后进「听音岗」，见到可锁定目标才尝试开火，30.6 秒时阵亡，击杀 0。另一次持续尝试开火、见敌后保持距离，90 秒时生命 91、击杀 3，返回摊位后有 18 金。两条脚本路线不足以估计真人胜率。 |
| 四敌对照 | 固定同一组两近战、两远程，同时引怪。手枪清场 5.16 秒、掉 18 血，手枪加霰弹枪清场 2.86 秒、未掉血。该场景固定了敌人站位和走位策略。 |
| 普通手枪挑战第一层守关者 | 保持初始单枪、满血，把角色置于第一层祭坛旁，绕行射击。38.0 秒内开火 78 次，记录到 10 次蓄力，玩家阵亡时守关者仍有约 273/1100 血。与下行六槽路线使用不同走位策略，两组数值用于展示装备两端的体验。 |
| 手感调试 | 在暂停设置启用免费消费，实际刷新 5 次、购入 5 把武器，与初始手枪组成六槽，其中有红弩和红手枪。脚本把角色置于各层祭坛附近，保持正常血量和伤害，用游戏的射击、碰撞、击杀和结算流程连续下潜。三层分别耗时 1.98、3.06、3.82 秒，生命均为 100，最终显示「遗迹已净化」。[第三层交火](Images/070-试玩体验/boss-3.png) · [最终结算](Images/070-试玩体验/result-3.png) |
| 专项复现 | 用真实场景的摊位设置两条射线，实测索敌与子弹命中。预置诱饵冷却下限，经过升级卡结算核对前后数值。在留有掉落的一层击杀守关者并下潜，核对两层的金币和钱包。 |

运行方式为 Unity PlayMode 自动驱动。移动经角色物理更新，开火调用实际武器方法，画面取自游戏相机和 HUD 的 1600×900 离屏渲染。首层探索以普通配置进行。调试路线跳过楼层间的步行探索。操作延迟、真人首次理解用时、耳机听感、其他分辨率及独立包性能仍需对应设备上的人工试玩。

最终覆盖 21 个通过的 PlayMode 用例，包括片头解码、战斗、购物与背包往返、炸弹规避与地刺伤害、声音事件、步行视野、场景推进和结算。早期调试路线在结算动画尚未播完时发送下潜输入，随后改为等待页面可交互再点击，连续通过两次下潜及最终结算。

## 最先影响玩家的六项

| 优先级 | 玩家会遇到什么 | 证据与复现 | 修复后的验收点 |
| --- | --- | --- | --- |
| 高 | **枪不打鼠标指的敌人，还会一直打柜台。** 这是玩家能看见正确目标、也做出正确输入，仍得不到预期结果的一处。 | **受控实测。** 柜台后放近敌 4 格，左边空地放远敌 5.5 格，两只都在亮区，鼠标方向指向远敌。连续 72 个采样帧都优先锁近敌。手枪成功开火 4 次，两只怪均维持 32 血。[现场](Images/070-试玩体验/cover.png) | 保留家具后的可见性。枪口到目标间有实体遮挡时，优先能打中的目标。重测此局面，左侧远敌应掉血。 |
| 高 | **出生后的第一道难题是猜游戏希望我做什么。** 站着只亮脚边，HUD 突出诱饵和背包，移动、射击、用脚步探路、寻找祭坛的顺序都没有给出。 | **画面实测。** 起点在 (90,162)，唯一出口位于南侧约 18 格外；出生画面里看不到门。完整的基础操作清单位于 Esc 暂停页，开场 HUD 也没有提示 Esc。[出生画面](Images/070-试玩体验/spawn.png) | 保留黑暗探索。让第一次玩的玩家在出生房内就能发现移动会照亮前路、左键会射击，并说出本层要找什么。 |
| 高 | **效果已满的升级仍会收走一次选择。** | **受控实测。** 先将「诱饵调校」叠到 4 秒下限。之后正常升级又抽到这张卡。选中后从 Lv.3 到 Lv.4，冷却从 4 秒到 4 秒，另两项选择一并消失。无移速被动时「轻装行进」在 160% 上限也有同类风险。[升级画面](Images/070-试玩体验/capped-upgrade.png) | 三选一抽取时按本局实际数值检查收益。达到下限后，仍应给玩家三个有收益的选择。 |
| 高 | **死亡重开会重复同一套路。** 玩家学到门位和开局货架后，下一局会直接知道答案。 | **重开实测。** 点击「再来一局」，首层所有门的位置相同，四件首批商品的名称、顺序与价格相同。地牢随机数和商店随机数都从固定配置重置。战斗中做不同选择仍可产生不同结果。 | 若普通模式以随机探索为目标，每局生成并记录新种子，调试保留指定种子复盘。 |
| 中 | **第一层最早能找到的商店，第一次进去只能看。** 出门赚到钱后还得决定是否原路折返。 | **普通路线实测。** 开局 0 金，四件货为白弩 30、红弩 240、疾行发电机 60、回声铜铃 36，刷新需 4 金。击杀 3 只并回收掉落后有 18 金，原货架仍买不起一件；按每只 6 金的基础掉落，首件要收满 5 只。界面也没交代要带钱回来。[开局商店](Images/070-试玩体验/shop.png) | 明确商店是返程补给，或调整首批货与首房收入，让玩家能够预测第一次有意义的购买。 |
| 中 | **击败守关者会立即失去收取剩余战利品的机会。** 已经朝玩家飞来的金币也依赖游戏继续模拟才能入账。 | **受控实测。** 首层结算时地上有 21 个金币拾取物，钱包为 0；下潜后地面拾取物为 0，钱包仍为 0。结算只说明回血和装备继承。 | 确定结算时如何处理未拾金币。至少让玩家在确认下潜前知道会损失什么。 |

## 战斗、成长与听觉

| 问题 | 依据与影响 |
| --- | --- |
| **近战预警可能短到看不出。** | **数值推算。** 普通近战怪距玩家 1.4 到 0.8 格才显示攻击姿势，进 0.8 格就可结算伤害。以基础速度直线接近，玩家静止约有 0.12 秒预警，迎面奔跑约 0.054 秒。死亡截图里多只怪叠在角色脚边，姿势更难辨认。[失败现场](Images/070-试玩体验/lost.png) |
| **远程守卫可以卡在无效射位。** | **代码核对。** 玩家在射程内且同屏，双方之间只有挡弹家具时，守卫的视线检查可以通过。它会停下蓄力，打到家具后仍可继续原地尝试。与前述玩家索敌问题共用视线与弹道规则的差异。 |
| **三层守关战的主要差别是要打掉多少血。** | **实测与配置。** 三只分别有 1100、1485、1870 血，共用相同的定向十二发环弹、蓄力和接触攻击。六槽极端构筑在一、二层甚至能于首次环弹发射前结束战斗。要评估正常装备的难度，应同时观察玩家实际能看到几轮可辨认的攻击。 |
| **离场后仍可能收到守关者弹幕警告。** | **代码核对。** 激活后，攻击计时与 HUD 提示无距离或视线条件，蓄力音也没有应用普通怪音效的距离衰减。退回另一房间仍可能听到同样强度的警告，误以为危险就在身边。 |
| **陷阱少了一条与主题契合的感知途径。** | **代码核对。** 感应炸弹点火和爆炸、地刺抬起前，危险主要靠地面细圈、闪色与动画表达。爆炸没有专属音效，命中玩家才触发通用受伤音。与带蓄力音的守卫混战时，玩家很难凭声音分辨地面危险。 |
| **脚步声规则与教学有歧义。** | **代码核对。** 暂停说明把青色声波解释为诱饵，脚步也产生青色圈并惊醒敌人；连续移动不足 0.2 秒再完全停下，会重置第一次脚步的计时。碎步可以移动却既不发声也不照路。若这属于有意的潜行技巧，需要能被玩家发现。 |
| **同类合成可能让总火力下降，界面只展示升品。** | **面板计算。** 两把白霰弹枪全部弹丸命中时，基础持续输出约为 63.2 伤害/秒，合成一把蓝枪后约为 55.6，下降约 12%，同时腾出一个槽。两把白手枪约 44.4，合成后约 41.9。不计暴击、掩体、围攻，实战会受站位影响。空槽时尤其需要显示这项交换。 |
| **同一次升级的收益很难从卡面比较。** | **面板计算。** 基础暴击率 10%、倍率 2 倍时，「致命打击」把期望伤害系数从 1.100 提至 1.108，实际约增 0.73%。同时可抽到的首次「精密弹头」约增 20%。卡面没有当前暴击率和选后预估，容易高估“+8 个百分点”对总伤害的作用。 |
| **高品质武器的价值与部分数据读不出来。** | **画面与代码核对。** 紫弩穿透一次、红弩穿透两次，每次穿透后伤害乘 0.75；玩家第一次就能看到的 240 金红弩，商店和背包均未写穿透。高攻速下，商店待购物的间隔显示下限为 0.10 秒，实际武器和背包使用 0.05 秒。 |
| **六槽时角色的落脚点与危险提示容易混在一起。** | **调试路线画面观察。** 第三层近身时，环绕武器、枪口闪光、声圈、围攻圈和守关者集中在角色附近。辨认角色脚底及红色危险信号需要从多层效果中找。这项适合用满配画面验收。[六槽交火](Images/070-试玩体验/boss-3.png) |

## 导航、菜单和结算

| 问题 | 依据与影响 |
| --- | --- |
| **小地图白点无法告诉玩家自己在隔墙哪一侧。** | **实测与关卡数据。** 从出生位走到摊位，白点坐标始终为 (48,−8)。它标的是 36×36 大格的中心。在第一层「共振中庭」这样的中央有长隔墙的房间，站在墙两侧会看到相同的定位。 |
| **大支路和单点商店叠加了折返成本。** | **关卡数据。** 第一层「维修库」「遗忘兵库」「回声档案室」各占三个大格，却各只有一个出口。小地图能揭示房间外形，但进支路深入探索后，要花钱仍须返回出生摊位。普通路线中仅从首个战斗房返回就走了约 7 秒。[首层房间表](062-当前房间示意图.md) |
| **第一、二层激活守关者时提前承诺“通关”。** | **流程实测与文案核对。** 三层共用“击败它即可通关”。实际前两次击杀显示本层已净化，操作是下潜，第三次才结束本局。 |
| **片头可跳过，屏幕没有告知按键。** | **入口实测与代码核对。** 正常视频播完可以进标题，视频绘制期间支持空格或 Esc 跳过，却没有相应提示。尤其影响第二次启动。 |
| **局内设置按 Esc 会直接恢复战斗。** | **代码核对。** 从暂停进入设置，点击「返回暂停页」回到暂停，按 Esc 却切到 Playing。先前正与敌人交火的玩家会比预期早一层解除暂停。 |
| **切走桌面窗口有阵亡风险。** | **独立包配置推断。** Windows 配置启用了后台运行，失焦回调会取消升级按键，未将战斗置于暂停。需要用当前版本的独立包验证 Alt+Tab 的系统级表现。 |
| **静音偏好在重开时丢失。** | **代码核对。** 按 M 后本局音量为 0，重开加载场景，新的控制器会将主音量设为 1。对依赖静音游玩的玩家，失败重试后会突然有声。 |
| **失败页没有提供足以复盘的死因。** | **败北画面实测。** 在「听音岗」阵亡后，画面能看到房名、等级、击败数、用时和装备，没有最后伤害来源。敌群堆叠时，玩家很难决定下次该躲弹、离开地刺还是早点拉开距离。[失败现场](Images/070-试玩体验/lost.png) |
| **失败和胜利的确认手势不一致，局内也缺少回标题的出口。** | **界面实测与代码核对。** 点击失败页「再来一局」有效；胜利页有 Enter/空格确认，失败状态没有相同的全局快捷键。暂停菜单只有继续、设置、背包，最终结算只给重开。 |
