# 013-正式美术资源盘点与制作规格

## 制作前盘点

依据 `012-三层美术风格设计.md` 与当前运行代码盘点。原型仍是一层七房间；普通敌人只有同一种追击／接触攻击逻辑，Boss 只有守钟者环形弹幕。视觉变体不增加敌人行为。

| 对象 | 当前表现与实际动作需求 | 仓库资源状态 | 处理方式 |
| --- | --- | --- | --- |
| 主角 | `PlayerController` 运行时生成；待机、移动、射击、受击、死亡 | 青蛙角色及装备参考完整，但均为展示图 | 新绘独立透明动作帧，保留奶黄青蛙、青围巾、护耳、共振背包；枪械独立旋转 |
| 普通敌人 | 沉睡、调查、追击、接触攻击、受击、死亡 | 三层怪物展示图不能直接使用 | 新绘透明六姿态帧；第一层两种外观共用现有近战行为 |
| 守钟者 | 沉睡、移动、蓄力预警、攻击、受击、死亡 | 已有 Boss 场景参考，无独立动画 | 新绘 64 像素帧，绑定现有蓄力与弹幕事件 |
| 后续敌人与精英 | 目前没有独立行为实现 | 三层设计已明确，正式帧缺失 | 资源与预览就绪，不新增远程、召集、三层通关逻辑 |
| 地面 | `DungeonMap` 中每格 1 单位 | Pixel Crawler 有可复用的原生 16 像素地牢砖 | 第一层提取砖块并按主题重调色；后两层制作钢板、几何石板，重复边界一致 |
| 墙体 | 单格碰撞，代码生成方块 | 已有地牢墙体可作材料参考；缺主题拼装资源 | 按三层材料绘制顶面与短正面，保持单格底座，配置遮挡排序 |
| 门框 | 当前为四格常开通路，无门框美术 | 素材包有门形参考，缺当前四格通路配套 | 制作独立门柱，放在通路边缘，不用展示图整门遮住通路 |
| 装饰 | 当前无正式装饰 | 素材包有透明武器架等原生素材，可直接提取 | 复用武器架；补绘灯、箱、铜管、工坊压力罐、音叉柱、晶体等。无碰撞小道具贴墙放置 |
| 音叉枪 | 独立 Transform 随瞄准旋转 | 概念图中有造型，无独立枪械 | 制作独立 16×16 透明枪图、枪口与后坐反馈 |
| 响铃诱饵 | 投放后原地发声 | Raven 包中有通用图标，但不是当前铃铛造型 | 补绘 16×16 铃铛，绑定现有脉冲事件 |
| 子弹、命中、状态 | 当前白方块染色、几何线圈 | 已有素材包不满足当前阵营与声学外观 | 补绘双方子弹、命中与枪口短动画、沉睡／警觉标记；保留现有真实范围声圈 |
| 阴影、血条、黑暗 | 程序状态相关表现 | 当前遮罩已实现 | 阴影补绘；血条和几何声圈继续程序驱动，黑暗规则不变 |

## 统一规格与资源位置

- 沿用项目 16 PPU、480×270 参考分辨率、Point、禁用 mipmap 和有损压缩。
- 主角与普通怪使用 32×32 帧，Boss 64×64，地砖与墙体 16×16，道具 16 或 32 像素。每个源像素对应 1/16 世界单位，避免通过非整数缩放压回旧占位图尺寸。
- 角色统一脚底基准与底部附近 Pivot；碰撞继续使用脚部占地圆，不用头部、天线、枪械和翅膀覆盖整个碰撞范围。
- 活动角色按脚底 Y 排序，墙体与装饰按底座排序；子弹与预警清晰显示；黑暗遮罩继续覆盖全部世界对象。
- 角色和独立物件使用硬透明边缘；阴影允许有限半透明。展示图中的文字、色卡和面板不导入。
- `美术/正式资源制作/原始帧图/` 保存为本轮用途重新生成的透明动作帧来源，原始概念图保留。
- `美术/正式资源制作/build_assets.py` 为可重复加工脚本，执行帧提取、透明阈值清理、统一像素网格、固定调色板及基线整理，不是简单缩小概念图。
- 正式游戏资源放在 `Assets/Echoes/Resources/Art/`，由 Unity 导入器按固定格切片，并由运行时美术目录加载。

## 批次与验证要求

1. 第一批：主角、第一层普通怪与 Boss、墙地砖、门柱、武器、铃铛和必要特效，接入后运行第一层验证比例、遮挡和动画。
2. 第二批：扩展第二、三层主题资源，在相同相机和运行对象上预览；未实现怪物放入资源图鉴，不进入正常关卡。
3. 截图必须来自真实运行的 Unity 场景；检查帧推进、透明边缘、拼接、脚底基线、死亡后动画与暂停关系。
4. 不生成 EXE，不修改核心战斗规则。最终结果、截图和限制记录在后续编号文档。
