# 098 第三层进房生成与金币回收

第三层恢复高密度版本的加权抽取参数，每层抽取 120 次，每次 9～15 只。进层只记录各房小怪的位置和职业，玩家进入时一次生成该房全部小怪，包括精英。第一、二层沿用 097 的进层生成与单房 18 只上限。

离开第三层房间时销毁已加载的房间小怪对象，按实际位置保存幸存者的血量、职业、警戒状态、目标与攻击计时。回访时只恢复幸存者。留在房内的尸体在淡出结束后销毁。守关者及其召唤物由原有战斗逻辑管理。

第三层未拾取的金币与玩家相距超过 32 个世界单位时销毁，金币余额只在拾取或守关结算收取现存金币时增加。

## 文件与编辑器配置

- 在 `Assets/Echoes/Settings/DefaultGameConfig.asset` 调整 `spawnCellDraws`、`spawnAmountMin`、`spawnAmountMax` 的第三项，以及金币清理距离 `goldDespawnDistance`。字段定义在 `GameConfig.cs`。
- `RunController.cs` 负责房间切换，`EnemyController.cs` 保存并恢复敌人状态，`GameArt.cs` 处理尸体淡出，`GoldPickup.cs` 处理远距离金币清理。

## 验证与已知限制

Unity PlayMode 用例 `MiddleRoomsUsePerFloorWeightedSpawnDraws` 覆盖前两层的初始怪数、第三层逐房加载、离房销毁及回访血量。`OnlyThirdFloorDiscardsDistantGold` 检查三层的金币保留和清理。守关者召唤、精英弹幕与分层敌人美术测试通过。

默认种子 713 的第三层共有 1453 只房间小怪，最大房间为 266 只。本机 D3D11 编辑器批处理测试中，第一次进入该房间的一帧为 41.3 ms，驻留时连续 60 帧平均 1.3 ms。一次生成整房仍可能带来进门瞬时停顿。驻留测试未测大量敌人同时追击或发射弹幕时的帧率。
