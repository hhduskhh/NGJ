# 开场与通关流程移除 CG

游戏启动后直接显示主菜单，点击「开始游戏」进入第一层。击败最终守关者后，原有的战场声圈和结算栏随即出现，玩家可以查看本局装备、统计并重新开始。

## 相关文件与编辑器配置

- `OpeningCinematic.cs` 在 Opening 场景中初始化主菜单，`GameHud.Feedback.cs` 负责楼层和胜利结算。
- 两段 MP4 已归档到项目根目录的 `美术/过场CG`，可单独预览。Unity 构建入口仍是 Opening、Prototype，无需设置 Inspector。

## 验证

PlayMode 用例 `TitleMenuOpensImmediatelyAndStartEntersFirstFloor` 和 `RevealConsumesFirstPressAndReleaseBeforeDescent` 分别检查菜单进入第一层、楼层与胜利结算，并检查这两条流程中没有视频播放器。
