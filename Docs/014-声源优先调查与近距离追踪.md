# 014-声源优先调查与近距离追踪

- 功能：普通怪听见声音后先调查固定声源；只有进入玩家步行总视野半径并且墙体视线畅通后，才追踪玩家当前坐标。步行总视野半径为步行主圈最大半径加渐变宽度，默认 `3 + 1.5 = 4.5`。
- 相关文件：`EnemyController.cs`、`Projectile.cs`、`GameConfig.cs`、`HearingAndVisionPulseTests.cs`。
- 编辑器配置：调整 `playerVisionRadius` 或 `gradientVisionRange` 会同步改变怪物发现玩家的距离；移除旧的独立 `sightRange`，避免两套距离失配。无需修改场景。
- 验证方法：在远处开枪或投掷诱饵，看怪物先走向声源而非立即跟踪玩家；远程命中时怪物调查该发子弹的发射位置；怪物接近到步行总视野范围后才变为追击状态。
- 已知问题：保留原有沉睡、跨房间移动与最后发现位置警戒规则。已经追击但再次失去视线的敌人会短暂沿最后发现位置前进，不再刷新玩家坐标；此时新声音可以重新引导它。守关者仍需祭坛激活。

远程受击不再直接赋予怪物玩家的实时位置。步行视野圈只揭示区域，不发布惊醒声音，因此仍可安静探索。

本轮针对性验证通过：远距离听觉与受击均先调查声源、进入发现半径后追踪玩家、离开范围后不再刷新玩家位置，以及重新调查新声源。
