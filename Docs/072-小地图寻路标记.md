# 072 小地图寻路标记

右上角面板在 1600 × 900 参考分辨率下为 224 × 272，地图占 200 × 200。白色黑边菱形按人物世界坐标连续移动。已探索的普通房间为蓝灰色，当前房间有亮青色描边；起点保留金色，首领房保留红色。真实门洞处的金色短线和朝外箭头指向未探索房间，门两边都探索过后显示浅灰短线。换层后按新楼层重新揭示。

## 相关文件与编辑器配置

- `Assets/Echoes/Scripts/UI/GameHud.cs` 管理面板、定位和房间贴图。换房或重建楼层时刷新贴图。
- `Assets/Echoes/Scripts/Core/GameConfig.cs` 提供 Minimap 配置。在 `Assets/Echoes/Settings/DefaultGameConfig.asset` 的 Inspector 中可以调整地图大小、玩家标记大小、描边宽度及颜色、两类门标颜色。面板和文字随地图尺寸排布，重新开始游戏后生效。
- `Assets/Echoes/Tests/PlayMode/FloorGenerationTests.cs` 包含两项小地图测试。

## 验证与已知限制

Unity 2022.3.62f3c1 下，两项 Minimap PlayMode 测试通过。覆盖房间首次揭示、同格内半个地砖的移动、门外箭头的位置以及过门和折返时的门标状态。

人工复验可从 Prototype 场景出生点沿金色箭头进门，再回到起点。菱形应随人物接近门口，折返时同一门洞应保持灰色。此次使用无图形模式运行测试，实际屏幕上的对比度和战斗时的遮挡感尚待试玩确认。
