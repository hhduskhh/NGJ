# 子弹飞行速度与尺寸

所有子弹的飞行速度提高到原来的 1.5 倍，单位为世界单位/秒。

| 来源 | 原速度 | 新速度 | 弹体尺寸相对改动前 |
| --- | ---: | ---: | ---: |
| 拾音手枪 | 22 | 33 | 1.2 倍 |
| 轰鸣霰弹枪 | 18 | 27 | 1.2 倍 |
| 静弦弩 | 26 | 39 | 1.2 倍 |
| 普通远程守卫 | 5.5 | 8.25 | 1.2 倍 |
| 守关者 | 4 | 6 | 1 倍 |

## 配置与验证

玩家武器的默认弹速在 `ShopCatalog.cs` 的武器定义中。守卫和守关者的弹速可在 Inspector 中选中 `DefaultGameConfig.asset` 后调整，脚本默认值在 `GameConfig.cs`。

`Projectile.cs` 将玩家和守卫子弹的精灵及命中半径同步放大，命中半径由 0.085 增至 0.102。`DungeonMap.cs` 的射线通路检查使用相同半径。守关者使用独立的尺寸配置 1.35。

可在 PlayMode 的开阔区域逐帧检查弹体位移，用位移除以游戏时间核对上表，并在 Inspector 中核对弹体缩放。靠墙射击时可检查放大后的弹体是否被掩体边缘拦住。实战躲避手感尚待试玩确认。
