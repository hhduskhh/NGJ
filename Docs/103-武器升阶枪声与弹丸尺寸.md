# 103 武器升阶枪声与弹丸尺寸

拾音手枪、轰鸣霰弹枪、静弦弩各自使用原有发射音色。每升一阶，播放音高降低 3 个半音，枪声尾音随之变长；弹丸显示直径增加白阶直径的 25%。霰弹的每颗弹丸使用同一档大小。

| 品质 | 音高相对白阶 | 弹丸显示直径 |
| --- | ---: | ---: |
| 白 | 原音 | 100% |
| 蓝 | −3 半音 | 125% |
| 紫 | −6 半音 | 150% |
| 红 | −9 半音 | 175% |

同类武器同帧开火时，使用本帧实际发射的最高品质音色；不同类别各自发声。弹丸增加的是显示尺寸，命中半径沿用原值。升阶、直接购买高品质武器都按武器当前品质计算。

在默认游戏配置的 Inspector 中可调 `shotSemitonesPerTier` 和 `bulletVisualGrowthPerTier`。相关实现见 [WeaponInventory](../Assets/Echoes/Scripts/Progression/WeaponInventory.cs)、[NoiseSystem](../Assets/Echoes/Scripts/Combat/NoiseSystem.cs)、[Projectile](../Assets/Echoes/Scripts/Combat/Projectile.cs) 和 [GameConfig](../Assets/Echoes/Scripts/Core/GameConfig.cs)。

在 PlayMode 运行 `CombatAudioTests.PistolUpgradesDeepenTheShotAndEnlargeTheBullet`，从白手枪连续合成到红阶，每阶实射检查声源音高和弹丸尺寸。可在局内比较同一武器相邻两阶；密集交火时的听觉辨识度仍需真人试听。
