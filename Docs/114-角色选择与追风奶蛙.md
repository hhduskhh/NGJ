# 114 角色选择与追风奶蛙

从 Opening 场景点击「开始游戏」进入[选人页](Images/114-角色选择/runner-selection.png)。点击角色卡进入第一层；返回或 Esc 可回到标题。阵亡后「再来一局」保留角色，重新计算本局成长。

## 属性与配置

在 DefaultGameConfig 的 Escape Frog 栏调整生命、基础移速、基础伤害系数、移速转伤害系数与转化上限。默认生命 90、移速 10.8、武器伤害为普通角色的 85%。追风每获得 1% 永久净额外移速，增加 1% 武器伤害；天生的 10.8 移速不计入转化。移速成长上限随被动封顶值计算，默认实际移速最高 21.6。普通角色沿用原有移速上限。

只拿轻装行进时，一张的伤害倍率为 0.9775，七张达到 1.70。疾行发电机与追风分别计算，加成相加后乘角色基础伤害系数。移速满时不再抽到轻装行进。

## 美术与相关文件

- 原画为 [主角2.png](../美术/主角2.png)。runner.png 编排待机、移动、攻击、受击、死亡各四帧。runnerLaugh.png 有八个姿势，按四秒笑声编排张臂、抖肩、弯腰与收势。Q 投掷时播放出手动作，F 成功点亮时播放大笑。[施法实机画面](Images/114-角色选择/runner-cast.png)
- ProductionArtImporter 将精灵按 64 × 64、32 PPU、Point 过滤和统一脚底轴心切片。GameArt 与 PlayerController 驱动身体动作。
- TitleMenu、OpeningCinematic 和 RunController 负责选人、载入与重新开局。GameHud 及结算页按角色显示头像，背包显示实际移速。

## 试玩与已知问题

Unity 2022.3.62f3c1 编辑器 PlayMode 通过四项针对性用例。OpeningCinematicTests 实际对按钮中心做射线点击，两名角色均能进入第一层；主角二经物理移动、开火、Q、F、升级封顶、手枪击杀、受击、阵亡和重新开局验证。对照用例覆盖原有满属性抽卡和疾行发电机。首轮截图发现血条和结算仍取旧头像，已修复并复验。选人页新增汉字已用项目像素字体重新烘焙。

本轮采用脚本驱动编辑器试玩。首层交火使用预设站位，满被动通过直接应用七次升级验证；三层自然养成节奏与真人满速操控手感仍待试玩。
