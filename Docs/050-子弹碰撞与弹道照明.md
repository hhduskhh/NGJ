# 子弹碰撞与弹道照明

`Projectile` 沿每帧实际移动的线段检测碰撞。子弹击中实体家具、墙或对方角色时结束；已有穿透升级可继续击中后续敌人。武器射程仍用于自动选敌。换层时清理旧子弹。

`DungeonVisibility` 和 `DungeonDarkness.shader` 沿玩家及敌方子弹已经经过的路径照亮地面，余光受墙体限制。GameConfig 的 `bulletTrailSeconds` 默认 0.35 秒，`bulletTrailRadius` 默认 1.15 格。同屏照明最多保留最近的 32 条弹道。

运行 RuntimeSmokeTests 的 SlowShotLightsItsPathUntilWallImpactAndDarknessReturns 可检查飞行时间、撞墙和余光消退。ShopTests 的 WeaponVolleyRangeAndPiercing 检查散弹与穿透升级。
