# 123 特殊音效背景音乐

开启「特殊音效」时，探索背景音乐使用《屋顶上的东南山》全曲。关闭时播放原曲 EmptyCity。在开始菜单选择后，进入探索即播放对应曲目；局内切换会从头播放另一首，跨层时继续循环。

`RunController.cs` 使用同一个音乐音源响应 `NoiseSystem.cs` 的设置变更。新曲为 `Assets/Echoes/Resources/RooftopMusic.ogg`，采用流式导入，沿用 RunController 的 Music Volume。

PlayMode 测试 `SelectedMusicSwitchesAndLoopsAcrossAllFloors` 验证曲目切换和跨层播放。自动测试不评判主观响度。
