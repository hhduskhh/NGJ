# 102 最终守关者冲刺方向预警

第三层守关者在冲刺前停步，脚下出现金色地面箭头。箭尖指向锁定方向，长度取冲刺速度乘持续时间，默认 3.52 个世界单位。玩家在这段时间横移即可离开原路线。冲刺开始和守关者死亡时都会收起箭头。战斗中只显示图形。

在默认游戏配置的 Inspector 中调整 `finalDashWarningSeconds`，默认 0.32 秒，按游戏时间计。实现位于 [EnemyController](../Assets/Echoes/Scripts/Combat/EnemyController.cs) 和 [GameConfig](../Assets/Echoes/Scripts/Core/GameConfig.cs)。

在 PlayMode 运行 `EnemyRoleTests.BossUsesFloorHealthAndAttackPatterns`。用例在箭头出现后移动玩家，核对预警时长、实际冲刺方向和各层攻击时序。箭头表示开阔地面上的预计行程，遇到实体障碍时实际位移可能更短。
