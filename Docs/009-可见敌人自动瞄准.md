# 009-可见敌人自动瞄准

- 功能：按住左键时，普通射击自动朝当前可见、未被墙体遮挡的最近存活敌人发射。声波临时揭示的敌人也可锁定；黑暗中、画面外、已死亡的敌人和未激活守关者不参与锁定。没有合适目标时使用鼠标方向。
- 相关文件：`PlayerController.cs`、`DungeonVisibility.cs`、`VisibilityAndUpgradeTests.cs`。
- 编辑器配置：保留 Input Manager 与左键开火方式，枪口朝向跟随所选目标。`GameConfig.playerVisionRadius` 决定常规可见范围，声波按当前实际揭示范围参与判断。
- 验证方法：将鼠标放在敌人反方向，按住左键，确认子弹命中可见敌人；敌人藏于黑暗或墙后时不锁定；声波到达后可锁定；无目标时子弹朝鼠标方向发射。
- 已知问题：当前直接瞄准目标位置，不预判运动，也不让已发射子弹转弯。近身常规视野采用圆形范围；瞄准另外检查墙体视线。当前版本不新增特殊技能，后续技能可调用 `TryFire(point, forceManualAim: true)` 明确保留指定方向。

鼠标位置仍独立用于 Q 诱饵投掷，不会被自动瞄准覆盖。

本轮验证：自动锁定实际命中、无目标回退鼠标方向、强制指定方向及黑暗目标排除的针对性测试通过。
