# 018-墙面视野锯齿修复

- 原因：墙面可见性原来按每个像素分别追踪视线，斜向射线先碰到相邻墙格时会遮掉当前墙格的一部分，在连续墙面上形成重复的三角形黑缺口。
- 修复：墙格统一根据朝向可通行区域的墙面采样点判断是否可见，消除墙格内部的三角形切口；距离渐变仍按像素计算。地面逐像素遮挡、墙角规则及其他玩法保持原有逻辑。
- 相关文件：`Assets/Echoes/Resources/DungeonDarkness.shader`、`Assets/Echoes/Tests/PlayMode/ObstacleVisibilityTests.cs`。
- 编辑器配置：无需更改场景、相机、材质资产或游戏配置。
- 验证：新增底部与左侧连续墙面的 104 个渲染采样点，同时检查墙后地面和地图外仍为黑暗；修复前已复现墙面亮度应大于 0.95、实际为 0 的失败。修复后本项及原有门洞、遮挡、多声源、瞄准相关测试共 5/5 通过，实际截图确认三角形缺口消失。报告与截图保留在本地 `TestResults/`。
- 已知问题：墙面显示以完整墙格为单位；圆形视野边缘继续采用原有渐变效果。
