# 020-脚步声惊醒敌人修复

- 原因：之前 `UpdateWalking` 只调用 `Reveal` 创建视野圈，没有创建 `NoiseWave`，敌人从未收到脚步声听觉事件。
- 功能：步行改为通过 `NoiseSystem.Emit(..., NoiseKind.Footstep)` 同时生成视野圈与实际声音传播，避免重复生成圈；补充轻量合成脚步音效。起步 0.2 秒、之后每 0.5 秒一次的节奏保持不变。
- 相关文件：`DungeonVisibility.cs`、`NoiseSystem.cs`、`HearingAndVisionPulseTests.cs`。
- 编辑器配置：脚步声音半径与步行主圈半径共用 `playerVisionRadius`，默认 3；圈外渐变只提供视野，不扩大惊醒范围。无需重新配置场景。
- 验证方法：静止和起步不足 0.2 秒不会惊醒附近沉睡怪；连续移动后，主圈内怪物被声波惊醒；仅处于渐变带内的怪物不被脚步声惊醒；关闭音效后听觉规则仍生效；停步不再产生新声波，原有圈照常收缩。
- 已知问题：脚步音效目前为合成占位音效。此规则取代 `014`、`015` 中此前“步行圈不发布惊醒声音”的旧约定。

本轮两项定向测试通过，涵盖实际行走惊醒、渐变带内敌人不惊醒、起步延迟、停步、静音状态下的听觉事件，以及同步调整后的调查与近距离追踪。未生成 EXE。
