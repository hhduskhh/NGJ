# 奶蛙开始界面

Opening 场景播放片头后显示定稿海报。空格或 Esc 跳过片头也会到达菜单。开始游戏加载 Prototype，设置面板可以切换全屏或返回，退出游戏在编辑器中停止 Play，在桌面版关闭程序。

海报为 Resources/TitlePoster.png，沿用用户选定的持黄铜音叉、穿深蓝外套的奔跑奶蛙。TitleMenu.cs 使用 uGUI 按海报比例放置可点击区域。OpeningCinematic.cs 在片尾、跳过及解码失败时共用同一个菜单入口。

编辑器中打开 Assets/Echoes/Scenes/Opening.unity 后点击 Play。直接打开 Prototype 用于调试战斗。自动验证用例 OpeningCinematicTests 覆盖视频解码、菜单贴图加载、打开设置、返回和开始游戏。海报文字随整张图片缩放。
