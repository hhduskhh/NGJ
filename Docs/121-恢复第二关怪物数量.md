# 121 恢复第二关怪物数量

第二关恢复到 097 减量前的初始刷怪规则：抽取 64 次，每次 4～8 只，移除第二关每房 18 只的配额。刷新点充足时全层为 256～512 只，实际数量随种子和可用刷新点变化。精英计入房间小怪数量，守关者和召唤物另计。

## 配置与实现

在 [默认游戏配置](../Assets/Echoes/Settings/DefaultGameConfig.asset) 的 Inspector 中，第二关使用 `spawnCellDraws`、`spawnAmountMin`、`spawnAmountMax` 的第二项。[GameConfig](../Assets/Echoes/Scripts/Core/GameConfig.cs) 提供默认值，[RunController](../Assets/Echoes/Scripts/Core/RunController.cs) 为第一、三关分别应用 18 和 64 只的单房配额。

## 验证

用默认种子 713 运行 PlayMode 用例 [MiddleRoomsUsePerFloorWeightedSpawnDraws](../Assets/Echoes/Tests/PlayMode/FloorGenerationTests.cs)，已通过。第一至三关实测初始小怪分别为 45、401、704 只，最密房分别为 18、90、64 只。第二关仍在进层时生成小怪，本次测试覆盖数量与房间分布，未测目标设备帧率。
