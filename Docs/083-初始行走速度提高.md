# 初始行走速度提高

玩家和三层怪物的基础行走速度统一提高到原来的 1.5 倍，单位为世界单位/秒。

| 角色 | 原速度 | 新速度 |
| --- | ---: | ---: |
| 玩家 | 6 | 9 |
| 近战行者 | 5.0666667 | 7.6 |
| 远程守卫 | 2.0666667 | 3.1 |
| 守关者 | 1.7 | 2.55 |

在 Inspector 中选中 `Assets/Echoes/Settings/DefaultGameConfig.asset`，可调整上述速度。新建配置的默认值位于 `Assets/Echoes/Scripts/Core/GameConfig.cs`。

验证时，对照两处配置检查四项速度，并与上一版本的对应值乘以 1.5 后比较。试玩时，无装备、无升级的玩家在空旷直道行走 18 单位应耗时约 2 秒。实际追逐手感尚待试玩确认。
