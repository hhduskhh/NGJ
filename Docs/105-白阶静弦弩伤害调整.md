# 105 白阶静弦弩伤害调整

白阶静弦弩的基础单发伤害由 24 提高至 30。初始角色无围攻加成时，普通命中后首层 32 血小怪剩 2 血；有一只敌人计入围攻时，普通命中造成 32.4 伤害，一箭即可击杀。

## 配置与验证

[武器定义](../Assets/Echoes/Scripts/Progression/ShopCatalog.cs) 中，静弦弩从白到红四阶的单发伤害为 30、43、77、138。白阶射击间隔为 1.10 秒，售价 30 金。当前默认配置读取这组武器定义，无需修改场景。

在 Unity Test Runner 的 PlayMode 中运行 [白弩战斗用例](../Assets/Echoes/Tests/PlayMode/AutoAimVisibilityTests.cs) 中的 `WhiteCrossbowKillsFirstFloorWalkerWithOnePressureStack` 和 `CrossbowHitsLitEnemyBeyondItsFormerTargetingRange`，分别验证一层围攻下击杀满血首层近战怪，以及远距离自动索敌命中。一箭击杀门槛按初始角色与普通命中计算；升级、被动和暴击会改变实际伤害。
