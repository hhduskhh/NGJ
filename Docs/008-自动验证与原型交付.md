# 008-自动验证与原型交付

## 功能与相关文件

增加独立 EditMode 与 PlayMode 测试程序集，并提供编辑器 Windows 构建菜单。

- `Assets/Echoes/Tests/Editor/CombatRulesTests.cs`：7 项规则测试。
- `Assets/Echoes/Tests/PlayMode/RuntimeSmokeTests.cs`：3 项运行集成测试。
- `Assets/Echoes/Editor/PrototypeBuilder.cs`：场景、配置、像素相机、字体与 Windows 构建入口。
- `TestResults/`：本地测试报告和探索、战斗、升级截图，不纳入版本管理。
- `Builds/Windows/`：本地 Windows 运行目录，不纳入版本管理。

## 编辑器配置与复验方法

使用 `2022.3.62f3c1`，打开 Test Runner，分别执行 EditMode 的 `Echoes.Tests` 和 PlayMode 的 `Echoes.PlayModeTests`。测试会加载 `Prototype` 场景，运行期间请勿手动操作游戏输入。

菜单 `Echoes > Create or Update Prototype Scene` 可重建入口场景、校准相机与材质、生成中文 TMP 字体资产；保留既有 `DefaultGameConfig` 数值。菜单 `Echoes > Build Windows Prototype` 输出 Windows 开发构建。

也可以用本机编辑器批处理，以下命令应逐个执行，每步等待前一个 Unity 实例退出，且工程不能在另一个编辑器中打开：

```powershell
& 'D:\Unity\Editor\Unity.exe' -batchmode -quit -projectPath 'D:\NGJ' -executeMethod Echoes.Editor.PrototypeBuilder.Create -logFile 'D:\NGJ\Logs\Setup.log'
& 'D:\Unity\Editor\Unity.exe' -batchmode -projectPath 'D:\NGJ' -runTests -testPlatform EditMode -testFilter Echoes.Tests.CombatRulesTests -testResults 'D:\NGJ\TestResults\editmode.xml' -logFile 'D:\NGJ\Logs\EditModeTests.log'
& 'D:\Unity\Editor\Unity.exe' -batchmode -projectPath 'D:\NGJ' -runTests -testPlatform PlayMode -testFilter Echoes.Tests.RuntimeSmokeTests -testResults 'D:\NGJ\TestResults\playmode.xml' -logFile 'D:\NGJ\Logs\PlayModeTests.log'
& 'D:\Unity\Editor\Unity.exe' -batchmode -quit -projectPath 'D:\NGJ' -executeMethod Echoes.Editor.PrototypeBuilder.BuildWindows -logFile 'D:\NGJ\Logs\Build.log'
```

截图测试需要渲染设备，请勿给 PlayMode 命令添加 `-nographics`。批处理没有 Game View 屏幕缓冲，测试通过显式 RenderTexture 渲染同一相机和 HUD；临时将 Canvas 改为相机模式并提高排序，随后恢复叠加模式。

## 已验证结果（2026-11-13）

- EditMode：7 / 7 通过。涵盖死亡、沉睡、距离边界和远距离排除，加成上限，升级经验与三选一去重。
- PlayMode：3 / 3 通过。实际验证七房间连通、敌人跨门移动、子弹命中和墙壁拦截、声波惊醒、声源调查、持续清醒、受击追击、固定敌人数量、经验升级暂停与恢复、普通升级不扩大枪声、主动扩音升级，以及不清场即可胜利和玩家死亡。
- 运行时间推进断言通过，排除了仅加载第一帧却没有运行的情况。
- 已生成并检查中文探索、战斗与升级截图；字体采用项目内 Noto Sans SC，原始字体和 OFL 许可证来自 [Google Fonts 官方仓库](https://github.com/google/fonts/tree/main/ofl/notosanssc)。
- Windows x64 开发构建成功，输出 `Builds/Windows/EchoesBelow.exe`，构建报告总大小约 129 MiB。运行程序时须保留同目录的 `EchoesBelow_Data`、`MonoBleedingEdge` 和 DLL，不能只单独复制 EXE。
- 独立 EXE 后台启动检查通过：Direct3D 11 与脚本程序集正常初始化，进程持续运行，`Logs/PlayerSmoke.log` 未发现运行异常、字体或着色器缺失；检查结束后已关闭该后台进程。
- 调整截图渲染顺序后，单独重跑界面截图测试 1 / 1 通过，三选一卡片的遮挡关系已人工检查。

## 已知问题与人工验收

自动测试通过不代表已经完成手感、难度和时长平衡。5–8 分钟体验目标、连续键鼠操作、诱饵引导的实际决策价值以及完整守关战仍需人工试玩反馈。固定地图、单一枪械、占位像素图和合成音效均为当前原型范围。未加入额外核心机制。
