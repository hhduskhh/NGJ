# 005-围攻加成与三选一成长

- 功能：仅计算玩家附近清醒且存活的敌人；默认半径 5、每只 +8% 伤害、最多计八只，即上限 +64%。青色细环显示统计半径，HUD 显示当前数量与伤害百分比。开枪时重新统计并锁定该发伤害。
- 相关文件：`CombatRules.cs`、`RunController.cs`、`UpgradeDefinition.cs`、`GameHud.cs`、`CombatRulesTests.cs`。
- 编辑器配置：围攻半径、每敌加成与上限，以及每次击杀经验、初次升级需求与递增经验均在配置资产中调整。
- 验证方法：远处惊醒敌人不增加加成；敌人靠近或死亡时统计变化；击杀到达经验门槛后暂停游戏并显示三个不同选项，按 1/2/3 或点击选择后恢复，溢出经验保留。
- 已知问题：当前六种升级可重复选择；单层数值需要试玩平衡。基础经验按击杀固定直接结算，无额外普通掉落表。

普通升级不扩大单次声波范围；“共振扩音器”明确标示为主动风险升级，每次枪声半径 +3。射速升级会提高开枪频率，仍保持每发声音半径不变。
