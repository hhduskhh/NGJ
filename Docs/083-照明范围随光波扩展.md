# 083 照明范围随光波扩展

全屏点亮从画面中心开始，圆形波前经过的地面和敌人依次显形，墙体不阻挡技能照明。波前外仍使用玩家视野、脚步回声和弹道的原有照明。自动瞄准按实际可见范围筛选目标，并检查弹道。笑声与屏内惊醒在按下 F 时触发。

## 相关文件与配置

`DungeonDarkness.shader` 在波前外绘制原有黑暗遮罩。`DungeonVisibility.cs` 按同一扩散进度计算敌人与危险提示的可见范围。在 DefaultGameConfig 的 Full-screen light 分组调整扩散时长，默认 0.7 秒，计入技能的 5 秒持续时间。

## 验证与限制

运行 PlayMode 的两个 ScreenLight 用例。在游戏中朝黑暗区域释放，观察技能边缘：内侧显形，外侧保留原有视野。敌人可能因脚步或枪声已提前显形。屏内惊醒测试覆盖墙后敌人及释放瞬间的屏幕边界。
