# 089 诱饵弹投掷动画与距离

按 Q 将铜铃投向鼠标。铜铃从角色手边翻转飞出，落地后开始响铃并计算诱敌持续时间。冷却从出手时开始，路径被墙或障碍物挡住时不消耗冷却。

投掷距离等于当前装备中最远的枪声半径。初始手枪可投 6 格，装备霰弹枪后可投 9 格，仅装备静弦弩时可投 3 格。扩音和消声加成会同步影响投距。响铃后的诱敌半径仍由诱饵属性控制。

## 文件与编辑器配置

`WeaponInventory.cs` 为开火和投掷提供同一套枪声半径计算。`PlayerController.cs` 负责限制落点、检查路径和启动冷却，`BellDecoy.cs` 负责飞行与落地响铃。在 `DefaultGameConfig` 的 Bell decoy 分组可调飞行时间（默认 0.4 秒）和弧线高度（默认 1.2 格）。

## 验证与已知限制

运行 PlayMode 用例 `VisibilityAndUpgradeTests.DecoyFliesToLoudestEquippedGunshotRangeBeforeRinging`，检查武器与扩音加成、超距落点、冷却以及落地前后的声波。手动验证时可在开阔处朝远方投掷，再隔墙投掷。弧线高度仅影响画面，碰撞按地面路径判断。
