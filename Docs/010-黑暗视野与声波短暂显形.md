# 010-黑暗视野与声波短暂显形

- 功能：玩家默认只看见附近半径 3 的圆形区域，范围外的地牢完全遮黑。枪声与响铃诱饵到达后揭示覆盖区域，波前继续扩散；到达最大半径后再维持 1.5 秒，然后恢复黑暗。没有永久探索亮图。
- 相关文件：`DungeonVisibility.cs`、`Resources/DungeonDarkness.shader`、`NoiseSystem.cs`、`GameConfig.cs`、`DefaultGameConfig.asset`、`VisibilityAndUpgradeTests.cs`。
- 编辑器配置：在配置资产中调整 `playerVisionRadius` 与 `echoRevealDuration`；声波半径和传播速度沿用已有配置。黑暗遮罩位于地牢绘制层上方，声波边界和 HUD 仍清晰可见。无需重建场景或调整 URP Renderer。
- 验证方法：移动时只有近身区域持续可见；向黑暗中射击或投掷诱饵，观察区域随波前打开并在短暂延时后再次变黑；诱饵多次响铃会刷新相应区域；升级暂停时显形倒计时也暂停。
- 已知问题：近身视野与声波揭示都采用圆形范围，未实现复杂墙体遮挡。普通射击自动瞄准另外检查墙体，避免向墙后敌人锁定。当前同时保留最多 32 次声波揭示，超过时替换最早的一次。

渲染遮罩与自动瞄准使用同一份显形数据和缩放后的游戏时间，避免黑暗中的敌人被自动锁定，或升级选择期间声波显形提前结束。

本轮验证：声波到达后显形、超时恢复黑暗与揭示后可锁定目标的测试通过；额外检查了渲染截图和屏幕边缘黑色像素，像素相机调整投影后的边缘遮罩覆盖测试通过。
