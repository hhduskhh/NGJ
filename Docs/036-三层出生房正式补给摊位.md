# 三层出生房正式补给摊位

## 功能与素材

- 替换 `ShopPlaceholder`、`ShopAwning`、`ShopSign`：三层各使用同一张 `f0_start_stall_96x64.png`，原生大小 6×4 世界格，不再拼装占位色块。
- 深青窄棚、暗金属柜台、黄铜音叉圆牌；与现有地砖、出生房 props 和商店音叉金币对照，限定色阶，硬透明边缘。
- 原始生成使用内置 image_gen，1536×1024 透明输出；最近邻采样到 96×64，再映射到 15 色遗迹调色板，Alpha 阈值 160，最终只有 0/255。
- 来源提示词：地下遗迹小型机械补给摊位，俯视 3/4 非等距，横向柜台朝下，窄深青棚、暗金属柜台与黄铜包角，侧挂粗线条 U 形音叉圆牌，一只小零件盒，三个清楚的大轮廓；透明背景，无人物、文字、按键、地板或界面。

## 相关文件与配置

- `Assets/Echoes/Resources/Art/Room/Common/f0_start_stall_96x64.png`：正式共用贴图及 Unity `.meta`。
- `ProductionArtImporter.cs`：Single Sprite，16 PPU，Point，Clamp，无压缩、无 mipmap，pivot `(0.5, 0)`。
- `StartStall.cs`：统一 kind、资源路径、5×3 占用与柜台前交互格。
- `RoomLayouts.cs`、`DungeonMap.cs`：占用在地图连通检查前加入，图形和碰撞由同一 spec 生成；按脚底 Y 排序。柜台位于出生点东北侧，保留中央通道与出生点。
- `GameArt.cs`：沿用正式资源加载入口，缺图直接报错；不依赖层数切换素材。
- `DungeonVisibility.cs`、`DungeonDarkness.shader`：仅摊位的不透明像素使用柜台前地格的正常视野渐变。防止自身地面碰撞把棚顶和招牌压黑；透明间隙、背后地面仍按原视线遮挡，世界排序不变。
- `ShopController.BeginFloor`：从实际摆放结果取得柜台前交互锚点；使用原有距离与视线判断、E 开店和 Esc 退出，不修改商品、价格或刷新规则。
- `StartStallTests.cs`：图形 Editor 中实际发送 WASD、E、Esc，逐层检查出生点、5×3 碰撞、柜台路径、商店状态和退出后移动，并从正式相机捕获画面。
- `ShopTests.cs`：原商店回归测试从正式柜台前操作；楼层重置通过正常 `AdvanceFloor` 流程验证。
- 并行第一层资源导出中的 `room_stall` 不覆盖本共用音叉摊位。

## 验证

- 正常入口 `Prototype` 中，三层均只有一个摊位，复用同一 Sprite；96×64、16 PPU、底中心 pivot、Point、无 mipmap、1 倍缩放均通过运行时断言。
- 各层 5×3 格全部不可走；出生点、柜台前交互格可走，出生点到柜台及出生房各门都有路径。中央四格通路不被占用。
- 三层均由原生键盘输入实际完成 `WASD 走近 → [E] 提示 → E 打开商店 → Esc 退出 → WASD 继续移动`；帧数与游戏时间确实推进。
- 遮罩保持启用，音叉招牌与台面清晰，棚顶未盖住柜台；摊位背后的地面视线仍被阻挡。
- 商店回归 7 项通过，包括购买、刷新、品质、合成、出售与楼层库存重置；加上三层真实按键验收，共 **8 项通过、0 失败**。报告 `TestResults/start-stall-release.xml`（不提交）。
