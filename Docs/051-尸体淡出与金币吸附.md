# 尸体淡出与金币吸附

## 游戏表现

- 普通怪和 Boss 死亡后保留倒地帧 0.3 秒，尸体与脚下阴影在接下来的 1.1 秒同步淡出。结束时停用敌人对象，换层时统一清理。死亡演出使用实时时间，因此进入升级或结算界面时也能播完。
- 金币落地后独立于尸体存在。玩家靠近至 4 格内且中间无墙体或实体障碍时，金币从掉落点起飞，逐渐加速追向玩家当前位置。飞行中玩家拉远仍可追随，若直线路径被挡则金币停下，等待再次满足吸附条件。
- 金币抵达玩家身边时入账一次。暂停、打开商店或选择升级时，金币停在原处。

## 配置与相关文件

在 Inspector 中选择 `Assets/Echoes/Settings/DefaultGameConfig.asset`。使用 `corpseHoldSeconds`、`corpseFadeSeconds` 调整尸体停留和淡出时间，使用 `goldPickupRadius`、`goldPullSpeed`、`goldPullAcceleration` 调整吸附半径、起步速度和加速度。

`EnemyController.cs` 在击杀时启动淡出，`GameArt.cs` 绘制死亡帧与阴影，`GoldPickup.cs` 负责追踪、遮挡判断与到账。`GameConfig.cs` 定义上述参数。

## 验证与边界

在 Unity Test Runner 的 PlayMode 页运行 `ShopTests.CorpseAndShadowFadeWhileDroppedGoldRemains` 和 `ShopTests.GoldFliesOnlyInRangeAndCreditsOnceOnArrival`。前者检查尸体与阴影的中间透明度和最终消失，后者检查范围外静止、范围内移动、暂停冻结和到账金额。进入 Prototype 场景可通过击杀普通怪并边走边拾取来观察飞行动画。

金币沿直线追踪玩家。转角处被挡后会留在最后可达的位置，玩家靠近并重新露面即可继续拾取。
