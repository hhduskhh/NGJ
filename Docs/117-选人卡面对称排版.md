# 117 选人卡面对称排版

两名角色各占相同宽度的卡面。原画采用相同裁切比例，边框、上下边线和左下角实战头像对齐。主角二的头像右侧只保留一行永久移速转伤害的比例与上限。

## 相关文件与配置

- `TitleMenu.cs` 的 HeroCard 负责卡面尺寸、头像位置与被动说明，换算系数和上限取自 Opening 场景的 GameConfig。
- `Assets/Echoes/Resources/SelectExplorer.png` 与 `SelectRunner.png` 分别从两张角色设定图取景，尺寸均为 505 × 450，沿用原有资源引用。

## 验证

运行 Unity PlayMode 的 OpeningCinematicTests，检查返回标题与分别选人进入第一层。在 1600 × 900 截图中检查卡面边缘、头像基线和单行被动说明；其他分辨率未单独截图。[实机画面](Images/117-对称选人卡面.png)
