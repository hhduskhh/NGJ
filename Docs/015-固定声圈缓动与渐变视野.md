# 015-固定声圈缓动与渐变视野

- 功能：静止时主视野半径为 0，角色身边仍有固定宽度的渐变带；移动时在连续行走满 0.2 秒首次生成视野圈，此后每 0.5 秒生成一次；开枪和诱饵发声时也在各自声源位置生成圈。圆心固定，不随人物移动。
- 相关文件：`VisionPulse.cs`、`DungeonVisibility.cs`、`DungeonDarkness.shader`、`PlayerController.cs`、`NoiseSystem.cs`、`GameConfig.cs`、`DefaultGameConfig.asset`、`HearingAndVisionPulseTests.cs`。
- 编辑器配置：默认主圈扩张 0.35 秒、最大值停留 0.5 秒、收缩 0.4 秒。扩张使用二次 easeOut，收缩使用二次 easeIn。步行主圈半径 3，渐变带宽 1.5，圈线透明度 0.06、线宽 0.02。数值均在 `DefaultGameConfig.asset` 中集中调整。
- 验证方法：静止时观察角色周围亮度从中心渐变到黑色；连续移动不足 0.2 秒无新圈，之后按 0.5 秒间隔在当时位置留下圈；停止后旧圈继续完成生命周期，不继续产生新圈；射击后移动，确认枪声圈留在发射位置。观察圈先快后慢扩张、保持最大值 0.5 秒、先慢后快收缩，圈外渐变宽度保持不变。
- 已知问题：视野仍使用圆形近似，不模拟复杂墙体遮挡；自动瞄准另行检查墙体。当前最多保留 32 个视野圈，超出后移除最早生成的圈。不同圈以较亮的结果合并，不叠加亮度。

## 实现约束

步行检测使用固定物理步长下的实际位置变化，按住方向键顶墙不会持续生成圈；停止后重新开始移动，会重新等待 0.2 秒。暂停和升级选择期间，生成节奏、扩张、停留和收缩一并冻结。

渐变渲染与自动瞄准使用相同的覆盖度算法。步行圈与枪声圈的总可见范围均为“当前主圈半径 + 固定渐变宽度”。渐变带不扩大实际惊醒范围；枪声的听觉扩张与可见主圈同步使用 easeOut。新的扩张时长配置取代旧的 `waveSpeed`，完整生命周期取代旧的 `echoRevealDuration`。

本轮验证通过：扩张减速、0.5 秒停留、收缩加速、固定渐变宽度、0.2 秒起步延迟、0.5 秒生成间隔、圆心固定、停步后不再生成、射击生成与暂停冻结；已检查静止和步行截图。仅运行本轮相关及受影响测试，未生成 EXE。
