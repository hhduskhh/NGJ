# 001-项目骨架搭建

- 功能：在仓库根目录建立 Unity 2D URP 项目，工作名《寂响遗迹 / Echoes Below》，第一版按 Windows 键鼠单机原型推进。
- 相关文件：`Assets/Echoes/Scripts/Core/`、`Assets/Echoes/Editor/PrototypeBuilder.cs`、`Packages/`、`ProjectSettings/`、`.gitignore`。
- 编辑器配置：沿用本机 `2022.3.62f3c1` 与附带的 Universal 2D 模板，URP 14.0.12。运行 `Echoes > Create or Update Prototype Scene` 生成场景与配置；不会重置已有配置数值。代码按运行时、编辑器和测试程序集分开。
- 验证方法：打开 `Assets/Echoes/Scenes/Prototype.unity`，点击 Play；控制台无编译错误；场景内存在 RunController、正交相机和 Global Light。
- 已知问题：Unity CLI 的 Pipeline 实时通道要求 Unity 6，本机版本采用原生编辑器批处理验证。工作名、目标平台是原型假设，尚未确定最终发行方案。

## 调参入口

`Assets/Echoes/Settings/DefaultGameConfig.asset` 集中管理玩家、枪械、噪声、敌人、经验、诱饵和守关者数值。升级实现位于 `UpgradeDefinition.Catalog`，不在每帧逻辑中硬编码。
