# 011-满经验暂停与升级确认结算

- 功能：经验达到门槛后，立刻暂停战斗并显示三选一；经验条保持满格，界面明确标示“已暂停”。点击卡片或按 1/2/3 后才应用升级、扣除本次经验并增加等级，然后继续游戏。溢出经验保留，足以再次升级时继续显示下一组选择。
- 相关文件：`RunController.cs`、`GameHud.cs`、`VisibilityAndUpgradeTests.cs`。
- 编辑器配置：继续使用统一 `RunState.Upgrade` 和 `Time.timeScale=0`，HUD 按未缩放的帧输入处理选项；暂停请求不会关闭待选升级界面。无需额外编辑器配置。
- 验证方法：击杀至经验满，等待后确认计时、角色、投射物和声波扩散均停止；经验条仍满；点击升级卡片后确认时间恢复、等级增加、经验扣除且溢出保留；Esc 不会跳过升级。
- 已知问题：当前没有升级重选或取消选项，必须从三个选项中确认一个。原有暂停流程仍保留，本轮修正的是选择前提前清空经验条的表现，并增加实际暂停与卡片点击恢复的针对性验证。

本轮验证：满条等待期间计时、角色、投射物与声波均冻结，卡片点击后等级和经验正确结算、溢出保留并恢复游戏的测试通过。本轮仅做针对性验证，没有重新生成 EXE。
