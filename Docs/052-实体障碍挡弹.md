# 实体障碍挡弹

玩家与敌方子弹沿实际飞行路径检查碰撞。地形里的墙体和实体家具会截停子弹，穿透升级仅作用于敌人。命中特效和弹道照明止于首次碰撞处。家具仍允许视线通过。

相关代码为 `Projectile`、`WeaponInventory` 和 `DungeonMap`。使用房间生成时为墙和家具创建的实体碰撞体，无需修改场景或增加图层。高大家具的挡弹范围沿用实体占地。

用 PlayMode 运行 SecondFloorRoomArtTests 的 NativeFactoryPropsMatchPhysicsAndKeepCounterReachable 和 ThirdFloorRoomArtTests 的 TenNativeAssetsPhysicsConnectivityAndProjectileBlocking，可验证家具允许通视并截停子弹。
