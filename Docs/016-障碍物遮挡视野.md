# 016-障碍物遮挡视野

- 功能：静止渐变视野、步行视野圈、枪声与诱饵视野圈均按各自圆心计算墙体遮挡。敞开的门洞允许视线通过，墙后区域保持黑暗；首先碰到的墙格本身可以被照亮，墙角不允许斜向穿透。多个视野圈仍按较亮结果合并，沿用现有扩张、停留、收缩与暂停规则。
- 相关文件：`Assets/Echoes/Scripts/World/DungeonMap.cs`、`Assets/Echoes/Scripts/World/DungeonVisibility.cs`、`Assets/Echoes/Resources/DungeonDarkness.shader`、`Assets/Echoes/Tests/Editor/ObstacleSightTests.cs`、`Assets/Echoes/Tests/PlayMode/ObstacleVisibilityTests.cs`。
- 编辑器配置：无需修改场景或 URP Renderer。继续在 `DefaultGameConfig` 中调整视野半径、渐变宽度和视野圈时长。遮挡数据直接使用地图的不可通行格，与墙体碰撞保持一致；地图初始化时上传一次遮挡纹理。视野圈轮廓位于黑暗遮罩下方，以免在墙后显示完整圆环。
- 交互规则：可见性查询、黑暗着色器和瞄准视线采用相同的逐格检查及墙角规则。远处诱饵能揭示自身所在一侧，但玩家自动射击仍须与目标直接视线畅通。声音惊醒范围沿用原型中穿墙传播的规则，听见声音不等于能被玩家看见。
- 验证方法：EditMode 验证水平、垂直、反向与斜向视线，首面墙体、门洞、短距离墙角及地图边界。PlayMode 验证门柱遮挡静止渐变、视野圈穿过门洞、墙后黑暗、画面与可见性查询一致、多声源独立遮挡、隔墙声音惊醒、视野到期和自动瞄准。人工可在两房间交界处移动、开枪、投掷诱饵，观察门洞后的亮区及墙后阴影。
- 验证结果（2026-11-13）：新增 EditMode 9/9、PlayMode 4/4 通过，渲染探针确认门洞、首面墙体和墙后黑暗与逻辑查询一致。相关回归在当前工作区为 11/13；两项射击命中测试失败。将当前提交基线及本轮改动导出到独立副本后，同组回归为 12/13，两项射击命中测试均通过，说明它们受未提交的美术接入改动影响。副本唯一失败项为旧测试 `ShootingCreatesAnAnchoredPulseThatFreezesWhilePaused` 的截图步骤：URP `Renderer2D` 初始化报 `Cannot create required material because shader is null`；该项在原工作区通过。本轮未发现 C# 编译或自定义黑暗着色器错误，已检查实际遮挡截图；未生成 EXE。
- 已知问题：遮挡针对当前固定地图的墙格；纯装饰不新增遮挡。尚无可移动或可破坏障碍物，若以后加入，需同步更新地图通行格与遮挡纹理。当前不增加探索记忆，视野圈消退后仍恢复黑暗。
