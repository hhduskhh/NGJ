# 073 全屏点亮

探索时按 F，照明区域从画面中心向外扩展，经过的地牢与墙后区域依次显形。技能从释放起默认持续 5 秒，冷却 15 秒。暂停、打开商店或背包时，两项计时都会冻结。换层会结束照明，并继承剩余冷却。左下角显示快捷键与冷却读数。

## 相关文件与编辑器配置

- `PlayerController.cs` 读取 F 键，`DungeonVisibility.cs` 同步黑暗遮罩和可见性查询。自动瞄准继续检查实际弹道。
- `GameHud.cs` 和 `GameHud.Screens.cs` 显示冷却与操作提示。`FusionPixelUI.asset` 包含技能名称的像素字形。
- 在 `Assets/Echoes/Settings/DefaultGameConfig.asset` 的 Full-screen light 分组中调整持续时间与冷却，对应 `GameConfig.cs` 的 `screenLightDuration` 和 `screenLightCooldown`。

## 验证与已知限制

Unity 2022.3 的 PlayMode 用例 `AutoAimVisibilityTests.ScreenLightRevealsViewportAndRechargesInPlayTime` 已通过，覆盖屏内外可见性、遮罩恢复、暂停和再次释放。可在 Prototype 场景中按 F 复验照明范围和左下角读数。本次自动验证调用技能入口，未进行实体键盘试玩。
