# 玩家与敌人基础移速提升

适配扩大后的地图，三层角色的基础移动速度统一乘以 4/3，单位为世界单位/秒。

| 角色 | 原速度 | 新速度 |
| --- | ---: | ---: |
| 玩家 | 4.5 | 6 |
| 近战行者 | 3.8 | 5.0666667 |
| 远程守卫 | 1.55 | 2.0666667 |
| 守关者 | 1.275 | 1.7 |

## 配置与验证

启动场景使用 `Assets/Echoes/Settings/DefaultGameConfig.asset`，新建配置的默认值在 `Assets/Echoes/Scripts/Core/GameConfig.cs`。在 Inspector 的 Player、Finite floor population 和 Gatekeeper 分组可调整对应角色的速度。

运行 PlayMode 用例 `EnemyRoleTests.RolesMatchFloorArtAndWalkerCanBeOutrun`，核对三层角色与行者实际追逐速度。无装备时，首次选择「轻装行进」后的速度为 6.72。无障碍直行 36 单位的理论用时从 8 秒缩短为 6 秒；房间内绕行与实战手感仍需试玩评估。
