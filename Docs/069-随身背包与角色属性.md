# 069 随身背包与角色属性

战斗、商店、暂停与升级选择期间按 Tab 可查看本局背包。战斗 HUD、商店和暂停菜单也提供背包按钮。查看期间暂停模拟，按 Tab、Esc 或返回按钮回到打开前的界面。背包记住上次查看的页签。

## 装备与属性

- 装备页显示六个武器槽及已持有的被动道具。点选查看武器数值或道具效果，同类道具合并显示持有数量。当前三种武器的四档图标和十二种道具均使用已有素材。后续缺图的格子显示问号。每页容纳十二种道具。
- 属性页采用单列十四行，左侧属性名与右侧读数共用 24 点 Fusion Pixel。读数取自本局角色与配置，涵盖生命、攻击、移动、防御、掉落、围攻与诱饵。
- 商店以主面板作为货架、装备槽与操作按钮的布局基准。下部提供拥有的道具预览，并可进入完整背包。

## 文件与配置

背包绘制位于 `GameHud.Backpack.cs`，商店布局位于 `GameHud.Shop.cs`。入口与返回逻辑位于 `GameHud.cs`、`GameHud.Screens.cs` 和 `RunController.cs`。图标通过既有 `PresentationArt` 引用加载，无需修改场景。新增文字已补入 `FusionPixelUI.asset`，后续可使用编辑器的 Echoes > Bake Interface Font 更新字库。

## 验证

在独立 Unity 副本运行 `BackpackShowsPurchasedItemsAttributesAndReturnsToShop` 和 `CatalogButtonStatesAndFullLoadoutRender`。检查购买后的持有物、十二种道具及叠加角标、六槽武器、属性读数、往返暂停状态、出售与合成。截图使用 1600 × 900 渲染目标，其他显示分辨率尚未逐一核验。
