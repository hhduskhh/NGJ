# 守关者弹幕频率与弹数提升

第一关和第三关的环形弹幕均由每轮 12 发调至 18 发。第一关发射周期由 1.8 秒缩至 1.2 秒，第三关由 0.9 秒缩至 0.6 秒。第二关沿用冲刺和召唤。

## 编辑器配置

在 `Assets/Echoes/Settings/DefaultGameConfig.asset` 的 Gatekeeper 区域，弹幕冷却 `bossAttackInterval` 为 0.8 秒，蓄力 `bossWarningDuration` 为 0.4 秒，每轮弹数 `bossBulletCount` 为 18。`Assets/Echoes/Scripts/Core/GameConfig.cs` 中的默认值与资源一致。第三关沿用双倍攻击频率。

## 验证与已知限制

在 Unity Test Runner 的 PlayMode 中运行 `EnemyRoleTests.BossUsesFloorHealthAndAttackPatterns`，检查第一、三关的首轮发射时间与实际弹数，以及第二关的冲刺行为。游戏中弹丸会被实体障碍挡住，可见弹数取决于玩家位置和房间遮挡。
