# 065-合并 P0 稳定性收口

## 功能

在 PR #3 合并版本上收口移动、战斗验收、菱形禁刷区和陷阱示意图一致性。保留同期主干新增的普通怪拖步声和第一层 EmptyCity 配乐，不新增核心机制。

- 敌人移动改到物理步进，用 Rigidbody2D 实际位置跟随路径，单步速度不超过到下一路径点的距离，修复低帧率下在门口折返。
- 沉睡、暂停及守卫停步期间仍记录实际位置，位置重置不算拖步声行走距离。
- 挡弹测试停止守卫的后续开火，避免把新一发子弹当成撞墙后残留。
- 听觉、射程和穿透测试先寻找无家具阻挡的通道；穿透目标固定，清理上一轮散弹，避免补给柜台、敌人移动和残留弹药影响断言。
- 菱形禁刷区沿完整内侧逐行生成，包含尖端及两侧；支持横向和纵向房间。
- 陷阱只能在锚点附近落位，保留门口净空；运行时保存计划位置，测试检查位移、数量和净空。
- 示意图导出运行时陷阱真实坐标、导航占地和完整禁刷区，重新生成三层示意图。
- 本次合并新增的三份同号文档改为 062–064，更新 README 和导出脚本引用；历史旧文档保留原编号。

## 已知边界

- 新增布局若无法在配置范围内为陷阱找到安全格，会明确报告生成错误；应调整图纸/家具或配置，不能把陷阱移到房间另一端。
- 示意图是导航格级的验收图，不表示精灵上半部的视觉轮廓。
- 原生键盘输入验收需要人工打开 Game View；自动场景流程测试不能替代完整人工试玩平衡。
