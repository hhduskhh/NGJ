# 021-技能升级与被动道具系统设计

## 设计目标与状态

将此前讨论的第一版属性、升级、核心技能和道具方案汇总为可供审查与后续实现的设计稿。成长采用“属性训练补强度、核心技能定路线、被动道具做取舍”，适配目前单层40只普通敌人。

本文保存已经讨论的设计，不代表新系统已经接入。当前代码仍是 UpgradeDefinition 中的六种可重复升级；完整新系统与[多武器系统设计](019-多武器系统设计与素材提案.md)均需在确认后实施。下列数值为第一轮调参起点，接入时应使用配置数据。

## 基础属性

| 属性 | 建议初始值 | 第一版规则 |
| --- | --- | --- |
| 伤害 | 公共伤害加成0% | 武器提供单发基础伤害；所有武器共享角色伤害加成 |
| 生命上限 | 100 | 提升上限时回复与增加量相同的生命 |
| 移动速度 | 4.5 | 同类加成相加，最终限制为基础速度的60%～160% |
| 闪避率 | 0% | 最终生效范围0%～50% |
| 暴击率 | 10% | 最终生效范围0%～100% |
| 暴击伤害倍率 | 200% | 暴击造成普通伤害的2倍，暂定最高500% |
| 攻速 | 公共攻速加成0% | 各武器使用自身基础间隔，最短实际间隔0.10秒 |
| 枪声半径 | 6 | 角色公共半径暂定3～12，武器再乘各自噪声系数 |
| 围攻加成效率 | 每只敌人+8%伤害 | 暂定最高每只+20% |
| 围攻计数上限 | 8只 | 暂定最多计入12只，初始总加成上限为+64% |

围攻上限表示“最多计算多少只敌人”。例如每只+10%、上限8只，满围攻就是+80%伤害。围攻统计半径保持5，仅统计附近清醒且存活的敌人；枪声半径不改变统计半径。

伤害、移速、攻速等同类百分比加成先相加；闪避率、暴击率和暴击倍率的“点”均指百分点。例如暴击率10%加8点为18%，暴击倍率200%加50点为250%。

多武器下，角色面板显示公共伤害／攻速加成，武器详情显示实际单发伤害和间隔。三种武器的基础伤害、射速、射程与品质数值以武器设计稿为准，不把旧单枪原型的0.28秒间隔作为全部武器的统一基准。

## 结算规则

```text
单粒伤害 = 该品质武器基础伤害
         × (1 + 角色总伤害加成)
         × (1 + 有效围攻人数 × 每敌加成)
         × 暴击系数

有效围攻人数 = min(用于围攻伤害计算的人数, 围攻计数上限)
攻击间隔 = max(0.10秒, 该品质武器基础间隔 / (1 + 攻速加成))
实际枪声半径 = 角色枪声半径 × 武器噪声系数
```

不暴击时暴击系数为1；暴击时使用角色暴击伤害倍率。手枪、霰弹枪、弩的噪声系数分别为1.0、1.5、0.5，初始实际半径分别为6、9、3。角色的3～12范围约束公共半径，不把不同武器的最终半径再次统一截断到3～12。

- 每把武器独立计时；一次攻击锁定发射时的攻击属性与围攻加成。
- 霰弹一轮共用一次暴击判定，弩的同一支箭在贯穿时共用暴击结果；具体规则与武器设计稿一致。
- 枪声半径同时影响惊醒范围和枪声显形主圈；现有墙体遮挡与固定渐变带规则继续适用。步行与诱饵的范围保持独立。
- 攻速增加会使声圈更密，但不额外增加单次半径；多武器声圈的半径不相加。
- 提升生命上限时回复等量生命。例如75/100获得上限+16后变为91/116。降低上限时仅截断超出新上限的当前生命，不触发受伤效果。
- 闪避按一次有效攻击判定一次；无敌期间不再次投掷闪避判定。成功闪避给予0.15秒保护，实际受伤沿用0.65秒保护。
- 暴击率、闪避率允许账面为负，实际最低按0%结算；后续增加先抵消负值。
- 属性转换只读取永久直接属性，不读取条件触发的临时效果或其他转换产生的数值，避免循环放大。训练、道具和核心技能的常驻直接加成按同一规则处理。
- 例如疾行发电机可读取长靴、训练及自身的永久移速加成，不读取穿行猎手的移动触发加成；同一轮计算不会再次使用转换结果。
- 暂停和选择奖励期间，条件效果持续时间、触发冷却、诱饵和武器计时一并冻结。

## 单局获取节奏

普通敌人每只直接结算1经验。每次升级需求调整为4、6、8、10、12经验，累计40只正好获得5次训练。守关者仍可提前挑战，后续奖励属于继续探索的收益。

| 内容 | 累计普通敌人击杀数 | 获取方式 |
| --- | --- | --- |
| 属性训练 | 4／10／18／28／40 | 三选一，选定后生效 |
| 被动道具 | 8／16／24／32 | 三选一，可放弃 |
| 核心技能Ⅰ级 | 12 | 随机三个不同核心技能中选一个 |
| 核心技能Ⅱ级 | 24 | 已选核心自动强化 |
| 核心技能Ⅲ级 | 36 | 已选核心自动强化 |

每局最多获得5次属性训练、4次道具奖励和1个三级核心技能。四件道具来自奖励次数，不另设与武器六槽共用的装备空间。

训练、被动道具和首次核心技能选择共享每局2次免费重抽；这是成长选择的重抽次数。武器商店每批一次免费刷新另行计算，规则见武器设计稿。核心自动强化不消耗重抽。

选择期间暂停。若同一击杀同时触发多种内容，先结算训练、再结算核心技能选择／强化、再结算被动道具，最后进入该批武器商店；全部处理完再恢复战斗。自动强化只展示结果，不增加一个必须确认的选择。满经验条、溢出经验和连续升级继续沿用现有暂停结算原则。

## 六个核心技能

每局只选择一个核心技能。下表每格为该等级的总效果，升级后替换旧值，不把三个等级累加。

| 核心技能 | Ⅰ级 | Ⅱ级 | Ⅲ级 |
| --- | --- | --- | --- |
| 围攻之心 | 每敌加成+2点；计数上限+1 | 每敌加成+3点；计数上限+2 | 每敌加成+4点；计数上限+3 |
| 穿行猎手 | 持续移动时伤害+12%、移速+4% | 伤害+18%、移速+6% | 伤害+24%、移速+8% |
| 致命校准 | 暴击率+10点；暴击倍率+40点 | 暴击率+15点；倍率+60点 | 暴击率+20点；倍率+80点 |
| 回避反射 | 闪避率+5点；成功闪避后攻速+20% | 闪避率+8点；触发攻速+30% | 闪避率+12点；触发攻速+40% |
| 低鸣猎手 | 枪声半径−0.8；伤害+10% | 半径−1.2；伤害+15% | 半径−1.6；伤害+20% |
| 血性驱动 | 生命不高于50%时伤害+20%、移速+4% | 伤害+30%、移速+6% | 伤害+40%、移速+8% |

### 围攻之心

已激活且位于围攻统计半径内的守关者，使本技能携带者的围攻伤害至少按4份计数计算，再受计数上限约束。例如只有一名守关者时，伤害计算用4份，界面实际敌人数仍为1。

此补偿只影响围攻伤害计数。孤战徽章等“实际附近敌人数”条件继续读取真实人数，不能把4份虚拟计数当成额外敌人。

### 穿行猎手

角色实际连续移动满0.5秒后生效，停止移动立即失效。按住方向但顶墙不移动不能维持效果。两个属性均属于条件加成，不作为疾行发电机的永久移速来源。

### 致命校准

暴击率和暴击倍率为常驻加成，对全部武器生效；遵守各自生效上限。

### 回避反射

闪避率为常驻加成。成功闪避后的攻速效果持续3秒，触发冷却4秒，重复触发不叠加。无敌期间忽略的伤害不算成功闪避。

### 低鸣猎手

半径减值先作用于角色公共枪声半径，再乘各武器噪声系数。伤害为常驻加成。缩小惊醒范围的同时也缩小枪声显形主圈。

### 血性驱动

按实时生命／生命上限比例判断，在不高于50%且角色存活时生效。未设计额外主动扣血操作；治疗或上限变化后重新判断阈值。

## 响铃诱饵

Q响铃诱饵继续作为全部构筑可用的战术技能，独立于每局选择的核心技能。

- 基础冷却12秒、声音范围9、持续4秒。
- 通过诱饵卷轴、回声铜铃强化。
- 诱饵没有武器噪声系数，不受角色枪声半径加减影响。
- 诱饵的声音、调查和近距离追踪关系沿用现有规则，本稿不新增强制嘲讽或伤害效果。

## 道具抽取与展示

| 第几次被动道具奖励 | 基础候选 |
| --- | --- |
| 1／击杀8只 | 白色三选一 |
| 2／击杀16只 | 蓝色三选一 |
| 3／击杀24只 | 紫色三选一 |
| 4／击杀32只 | 紫色三选一，20%概率将一个选项替换为红色 |

每轮候选不重复同名道具，已达持有上限的道具退出候选池；第四次成功触发红色时从两件红色道具中生成一个合法候选。重抽仍遵守当前奖励的品质规则。

会使生命上限低于20的道具不进入候选。道具可以放弃，训练必须选择。取得前展示实际变化，包括公共属性、各装备武器伤害与间隔、实际声音半径，以及达到上限后被截断的部分。

提高生命上限按统一规则回复增加量；应急修复器额外执行其明示治疗。第一版续航来自有限奖励和击杀，不加入等待即可无限自然回血的机制。

## 构筑示例

| 路线 | 核心或代表道具 | 打法与取舍 |
| --- | --- | --- |
| 聚敌围攻 | 围攻之心、扩音枪口、承压线圈 | 用更大敌群换输出，需要移动空间；可搭配霰弹枪 |
| 低鸣暴击 | 低鸣猎手、消声套管、聚焦透镜 | 分批交战，远处信息更少；可搭配弩和诱饵 |
| 高速游击 | 穿行猎手、轻装框架、疾行发电机 | 依赖持续移动，生命偏低 |
| 闪避速射 | 回避反射、偏转护符、偏转发条 | 生存投入转为攻速，仍有连续受伤风险 |
| 厚血重击 | 血铸弹芯、厚衬外套、伤害训练 | 稳定承伤，移动和射击节奏较慢 |
| 背水输出 | 血性驱动、玻璃弹仓、暴击组件 | 低生命爆发更高，剩余容错更低 |

厚血重击可以选择血性驱动形成高生命半血打法，或选择致命校准补充爆发。不要求凑齐固定套装，也不另加套装数量奖励。

## 与武器购买的独立关系

技能、训练和被动道具的品质用于奖励强度／道具稀有度；它们不参与武器二合一。武器品质、价格与合成规则由武器设计稿定义。

每只普通敌人计划同时结算1经验和6零件。经验用于上述五次训练，零件用于商店购买武器，核心与免费被动道具另按击杀里程碑发放。每个奖励节点只结算一次。

例如第24只普通敌人击杀后，核心升至Ⅱ级，领取第三次紫色被动道具，再进入第三批武器商店；附近敌人的时间与武器计时在整段结算期间保持暂停。第40只之后是第五次训练和最后一批武器商店。

多武器会叠加放大角色公共属性，不再沿用单枪时代的总输出预算。与武器稿联合试玩时，先以正常成长三至六把武器对守关者交战约15～25秒为调参目标，再决定敌人耐久；本文不将该目标当成已验证结果。

## 已知问题与待确认事项

- 全部数值仍需实际试玩验证，尤其移速／闪避转输出、全局属性同时强化六把武器，以及霰弹共用暴击的爆发。
- 血铸弹芯“每20点生命上限”的效果需要在接入前确认按完整20点取整，还是允许按比例连续计算；此前设计未定，本轮保留原数值。
- 首次核心选择取三个随机候选，可能没有玩家最想要的路线；先使用共享重抽体验，再决定是否调整供给。
- 数值和奖励节奏针对当前40只普通敌人的单层；三层总流程应重新安排经验、道具、核心等级和购买预算。
- 尚无技能／道具正式图标和触发特效，不把武器品质板当作技能素材。
