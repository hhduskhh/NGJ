# 042 战场结算与本局装备

原有居中结算窗口改为底部结算栏。战场定格在角色和守关者所在的位置，战斗 HUD 在结算时收起，继续下潜后恢复。探索失败直接出结果，楼层净化和最终胜利沿用可跳过的声圈演出。

## 设计与资源

参考《土豆兄弟》实机结算里并列展示武器、道具与本局数值的组织方式。胜负页按实际库存展示六个武器槽、武器名、品质色和等级刻度、被动道具与叠加数量，再列出楼层进度、房间、击败数、耗时和金币。中途净化使用短横条，显示本层守关者、恢复比例与下潜按键。[参考截图](https://images.steamusercontent.com/ugc/2330118878979608009/A4B755873666A2900AF740AFF3E82901DCAA2964/)

## 文件与配置

- `GameHud.Result.cs` 负责结果布局和战斗 HUD 收起、恢复。`GameHud.Screens.cs` 接入现有状态，`GameHud.Feedback.cs` 在声圈演出中淡入轻遮罩。
- `HudFeedbackTests.cs` 从新的结算根节点验证跳过和继续操作。
- 使用现有角色、守关者、装备、金币和按钮 Sprite。无需调整图集、场景或 Inspector 引用。

## 验证与已知限制

独立 Unity 副本 PlayMode 验证了演出首次确认只展开结算、再次确认才下潜，以及下潜后地图恢复。截图用例在原型场景中检查了单把初始武器且无道具的失败页、第一层净化和满装备最终胜利。满装备由测试注入，胜利通过击败第三层守关者触发。验收截图为 1600 × 900，其他宽高比尚未实机复核。
