# 124 最短通关时间

击败第三层守关者时，游戏将本局用时与本机历史最快成绩比较。首次通关或用时更短时立即保存。两个角色共用纪录，重新开局或退出后再启动均可保留。

胜利和失败结算均显示本局用时及最快通关时间，精确到百分之一秒。首次通关前显示「暂无」。计时沿用三层累计的实际游玩时间，打开暂停、背包、升级、商店或停留在层间结算时暂停累计。

- 相关文件：`RunController.cs` 在最终胜利时写入 PlayerPrefs，`GameHud.Result.cs` 负责结算显示。
- 编辑器配置：无需修改场景或挂载组件。
- 验证方法：运行 PlayMode 测试 `BossDefeatAdvancesThroughThreeFloorsAndPreservesRunState`，覆盖首次通关、已有更快或更慢成绩、跨层与重新开局。手动验证时可在通关后退出游戏，再次启动并查看下一局结算。
- 已知限制：纪录保存在当前设备的本地用户设置中，清除游戏数据会清除纪录。
