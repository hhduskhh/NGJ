# 三关守关者攻击与血量

| 关卡 | 满血 | 弹幕周期（含蓄力） | 冲刺周期 |
| --- | ---: | ---: | ---: |
| 第一关 | 2,200 | 1.8 秒 | 无 |
| 第二关 | 7,425 | 无 | 1.4 秒 |
| 第三关 | 18,700 | 0.9 秒 | 0.7 秒 |

血量按各关原值分别乘以 2、5、10。第一关的 12 发环形弹幕保留红圈与蓄力音效，移除了攻击前的文字提示。第二关每次起冲时锁定玩家方向，以每秒 11 个世界单位移动 0.32 秒，碰到玩家最多造成一次伤害。第三关的弹幕和冲刺独立计时，可以重叠。

## 编辑器配置

在 `Assets/Echoes/Settings/DefaultGameConfig.asset` 中调整参数。`bossAttackInterval` 是弹幕冷却，`bossWarningDuration` 是蓄力时间，两者之和为弹幕周期。`bossDashInterval`、`bossDashDuration`、`bossDashSpeed` 控制冲刺，`finalBossAttackRate` 同时调节第三关两种攻击的频率。`floorBossHealth` 存放相对于基础血量 1,100 的最终倍率。

参数定义在 `Assets/Echoes/Scripts/Core/GameConfig.cs`，攻击与碰撞处理在 `Assets/Echoes/Scripts/Combat/EnemyController.cs`。

## 验证与已知限制

在 Unity Test Runner 的 PlayMode 中运行 `EnemyRoleTests.BossUsesFloorHealthAndAttackPatterns`，逐关检查满血、实际出招类型与首次出招时间。冲刺沿直线受实体阻挡，贴墙时实际位移会缩短。三关难度仍需试玩评估。
