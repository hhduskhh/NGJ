# 100 运行时脚本模块归档

原先修改一次商店或装备功能需要在 Core、Combat、World 三处寻找逻辑。现在商品目录、购买规则、金币拾取、库存与升级定义集中在 `Assets/Echoes/Scripts/Progression/`。

地图生成保留在 World。视野圈和遮挡计算归入 Visibility，美术绑定、相机、爆炸特效与片头播放归入 Presentation。围攻伤害等计算随 CombatRules 归入 Combat。完整的目录职责与脚本入口见 [README 的运行时脚本表](../README.md#运行时脚本)。

## 编辑器配置与验证

这些目录均位于 `Echoes.Runtime.asmdef` 下，编辑器无需重新绑定组件。移动脚本时一并移动同名 `.cs.meta`。审查迁移提交时可用 `git show --find-renames --summary` 核对脚本及其元数据的重命名相似度均为 100%。

## 已知限制

目录用于明确文件归属，程序集内仍允许跨目录调用，例如 WeaponInventory 通过 RunController 读取配置和玩家属性。早期功能记录中的脚本路径对应当时的版本，可按原文件名在新目录中查找。
