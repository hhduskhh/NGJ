# 054-分层地图尺寸

## 功能

三层地牢的房间格不再固定为 5×5，改为逐层扩大：

| 楼层 | 房间格 | 单格尺寸 | 整图尺寸 |
| --- | ---: | ---: | ---: |
| 1 | 3×3 | 36×36 | 108×108 |
| 2 | 4×4 | 36×36 | 144×144 |
| 3 | 5×5 | 36×36 | 180×180 |

每层仍铺满全部格子：起始房和 Boss 房各占一个单格，其余格子由 1×1、1×2、1×3、2×2 与 L 形房间铺满。起始房固定在顶排中间，Boss 房是该层最后一个房间且保持单入口。正常生成要求至少出现两种多格房型；随机生成失败时回退到全单格房间布局。

## 配置

`Assets/Echoes/Settings/DefaultGameConfig.asset`，字段定义在 `Assets/Echoes/Scripts/Core/GameConfig.cs`。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `floorGridSizes` | `{3, 4, 5}` | 每层房间格边长，索引 0/1/2 对应第 1/2/3 层；运行时钳制在 3–5 |

其余生成参数继续沿用：`generationAttempts`、`extraDoorChance`、`spawnCellStride`、逐层刷怪参数。

## 实现

- `DungeonPlan` 的 `GridSize` 和 `StartCell` 从静态常量改为实例属性；构造时按 `gridSize / 2` 计算顶排起始列。
- `DungeonMap` 的 `GridSize`、`Width`、`Height`、`walkable`、`floor`、`cellRooms` 改为按当前楼层动态分配；裸 `DungeonMap` 仍默认 5×5，供仅测试视线/网格的用例使用。
- `DungeonMap.Room` 记录所属楼层的 `GridSize`，并提供 `CellOriginY`。`RoomLayouts`、`RoomInterior` 和三层的道具/陷阱坐标改为使用房间自身的行高换算，避免小地图尺寸改变后道具错位。
- 小地图纹理按 `MapWidth × MapHeight` 创建；换层或外部直接重建地图时，`DrawMinimap` 会检测尺寸并重建纹理，玩家标记按 `GridSize` 调整间距。
- 暗区遮罩、障碍表面图和 `PropSurfaceMap` 原本使用 `MapWidth/MapHeight`，随动态尺寸自动重建。
- 回退布局改为全单格房间铺满棋盘；不依赖形状组合，因此 3×3/4×4/5×5 都能生成连通地图。

- PlayMode 分组回归通过：`DungeonGenerationTests`、`FloorGenerationTests`、`RuntimeSmokeTests`、`HearingAndVisionPulseTests`、`VisibilityAndUpgradeTests`、`ShopTests`、`FirstFloorRoomArtTests`、`SecondFloorRoomArtTests`、`ThirdFloorRoomArtTests`、`FormalArtTests`、`ObstacleVisibilityTests`、`RoomTrapTests`、`RoomPropPhysicsTests`、`PropOcclusionTests`、`RoomCombatTrialTests`、`RoomArtAcceptanceTests`、`PresentationArtTests`、`GameplayVisionCaptureTests`、`HudFeedbackTests`、`FeelDebugModeTests`、`CombatAudioTests`。
- `ThirdFloorRoomArtTests` 的家具挡弹检查改为等待碰撞发生，不再假设固定 0.2 秒内必定飞完固定距离，避免批处理低帧率下的误报。

## 已知问题

- `Docs/035-当前房间示意图.md` 和 `Docs/Images/房间示意图-20261114/` 是按旧的 5×5 第一层导出的，当前已过期。需要重新运行 `RoomSchematicExportTests.ExportCurrentFloorSchematics`，再执行示意图渲染脚本。
- 3×3 楼层只有 7 个中间格，单层通常只能容纳 2–4 个中间房，因此不会同时出现全部五种房型；美术验收需跨种子寻找缺失房型（当前测试已按此处理）。
- Boss 房位置仍由种子随机决定，不保证位于底排；只有回退布局固定在底排中间。
- `floorGridSizes` 当前只支持 3–5；若以后超过 5，需要同步扩大裸 `DungeonMap` 的默认测试数组或改为完全动态初始化。
