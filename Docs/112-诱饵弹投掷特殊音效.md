# 112 诱饵弹投掷特殊音效

开启「特殊音效」后，成功按 Q 扔出诱饵弹时播放《奶龙教学嘎嘎滴辣虾》开头两秒。关闭后使用原有的落地铃声。两种模式下，落地声波都按原有节奏吸引敌人。

资源为 `Resources/CombatAudio/DecoyThrowSpecial.wav`，44.1 kHz 单声道，尾部淡出 10 毫秒。`BellDecoy.Throw` 在投掷时选择音效。可在 DefaultGameConfig 调整 Decoy Throw Volume。

运行 PlayMode 用例 `DecoyFliesToLoudestEquippedGunshotRangeBeforeRinging`，检查片段长度、投掷时的播放状态和落地声波。可在设置里切换「特殊音效」后分别按 Q 试听。已知限制是自动测试无法判断语音与战斗声音混合时的主观响度。
