# 032-墙面部分遮挡边界复发修复

- 原因：上次按墙格中点统一判断可见性，消除了墙格内部的三角形缺口，但遇到门洞、内部障碍造成的部分遮挡时，阴影边界仍会按整格跳变。后来加入的对角补光还会在正面已被遮挡的墙格上执行，错误点亮阴影区域。原测试仅覆盖整面墙可见，未覆盖此情况。
- 修复：射线仍终止于墙外表面，沿墙方向采用当前像素坐标，使墙面阴影连续跟随投影位置；仅对没有正邻空地的内墙角保留对角补光，避免绕过已遮挡的正面。
- 相关文件：`Assets/Echoes/Resources/DungeonDarkness.shader`、`Assets/Echoes/Tests/PlayMode/ObstacleVisibilityTests.cs`。
- 编辑器配置：无需调整场景、相机或配置资产；原有视野半径、渐变、地面遮挡、碰撞、瞄准和其他玩法不变。
- 验证：新增单格障碍投影到连续墙面的确定性场景，以几何投影位置为预期，覆盖四个旋转方向、480 个墙面采样点及可见地面、障碍阴影、墙后黑暗。修复前稳定失败，修复后新增测试及原有墙面、门洞、多声源与瞄准回归共 6/6 通过；已检查前后渲染图。
- 本地报告与截图：`TestResults/wall-shadow-before.xml`、`wall-shadow-after.xml`、`wall-shadow-before-0.png` 至 `wall-shadow-before-3.png`、`wall-shadow-0.png` 至 `wall-shadow-3.png`，均不纳入版本管理。
- 已知问题：遮挡轮廓仍遵循现有地图格形状。
