# 《寂响遗迹》玩法说明

选择角色，探索三层随机地牢。每层都可以先打怪升级、逛商店，再挑战守关者。击败第三层守关者即可通关。

**探路与战斗**　用 WASD 移动，按住鼠标左键持续射击。脚步和枪声能短暂照亮周围，也会惊醒敌人。武器会自动瞄准最近的可见敌人，没有目标时朝鼠标方向开火。身边蓝圈内可见且清醒的敌人越多，你的伤害越高，加成有上限。

**升级与购物**　击败敌人获得经验，经验满后点击升级卡，或按 1 / 2 / 3 选择。每次升级都会提高生命上限并回满生命。拾取金币，靠近商店按 E 购买武器和被动道具。

**挑战守关者**　小地图的红色箭头提示通往守关者房间的路线。准备好后，靠近房内的祭坛按 E 开战。前两层获胜后按 E 进入下一层。

| 其他操作 | 按键 |
| --- | --- |
| 朝鼠标方向投出响铃诱饵，吸引敌人 | Q |
| 短暂照亮全屏，同时惊醒屏内沉睡的普通敌人 | F |
| 查看背包和角色属性 | Tab |
| 暂停游戏 | Esc |
