# 082 全屏点亮扩散特效

按 F 成功释放全屏点亮时，一圈青白色光从画面中心向外扩散，内侧的青色余光逐渐淡出。波前在默认 0.7 秒内扫过四角。照明、笑声与屏内惊醒在释放时同时生效。游戏暂停时光圈停在当前位置，恢复后继续扩散。

## 文件与配置

- `DungeonVisibility.cs` 用游戏时间计算扩散进度，交给 `DungeonDarkness.shader` 在场景遮罩层绘制光圈。圆形半径按相机宽高比计算，HUD 绘制在其上方。
- 在 `DefaultGameConfig` 的 Full-screen light 分组中调整 `Screen Light Wave Duration`，单位为秒。

## 验证与限制

在 Unity Test Runner 的 PlayMode 中运行 `AutoAimVisibilityTests` 下的两个 ScreenLight 用例，检查波纹进度、暂停、照明恢复及惊醒行为。使用图形设备运行时，测试会将扩散中的画面保存至 `TestResults/screen-light-wave.png`。将扩散时间设得长于照明时间时，光圈会随照明一起结束。
