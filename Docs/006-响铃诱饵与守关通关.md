# 006-响铃诱饵与守关通关

- 功能：Q 向鼠标方向投掷响铃诱饵，距离受限、投掷路径受墙阻挡。落点持续发出青色声波，吸引沉睡、调查或警戒敌人。到达守关者祭坛附近按 E 开战；守关者红色蓄力环预警后发射环形弹幕，击败后立即通关，不要求清空普通怪。
- 相关文件：`BellDecoy.cs`、`PlayerController.cs`、`EnemyController.cs`、`RunController.cs`。
- 编辑器配置：诱饵距离、半径、持续时间、冷却；守关者生命、伤害、预警时间、弹速、弹数与攻击间隔均在配置资产中可调。
- 验证方法：Q 在可见地板放置铃铛，检查冷却与敌人调查方向；隔墙投掷显示阻挡提示；祭坛前 E 激活守关者，观察预警与弹幕；普通怪仍存活时击败守关者也能胜利。
- 已知问题：只有一种诱饵与一个基础守关者。未实现精英、召唤、阶段切换。5–8 分钟是体验目标，当前尚需人工整局试玩确认时长。
