# 004-声波惊醒与持续敌人状态

- 功能：枪声与响铃诱饵产生实际扩散声波。外侧细圈标示本次声音最大半径，扩张亮圈标示传播前沿；到达敌人时才通知听觉。声音忽略墙体，弹丸与视线仍受墙体阻挡。
- 相关文件：`NoiseSystem.cs`、`EnemyController.cs`、`DungeonMap.cs`。
- 编辑器配置：`gunNoiseRadius`、`waveSpeed`、`sightRange`、`enemySpeed` 在配置资产中调整。每层初始化一次普通怪，默认五个战斗房各八只，另有一只守关者。
- 验证方法：在门口射击，看相邻敌人由灰色横线变为金色标记，向声源调查；被看到或被击中后显示红色竖线并追击。绕过房间后观察其继续沿门口寻路；丢失视线后在最后发现位置附近警戒。
- 已知问题：寻路采用小地图格子的广度优先搜索，适合当前规模；不包含复杂声学绕墙、敌人听觉差异或精英呼叫同伴。守关者需祭坛主动激活，不受普通声音唤醒。

## 状态约束

沉睡 → 调查 → 追击；丢失目标 → 警戒。警戒敌人可以被新声源重新引导。已经追击玩家的敌人优先保持当前目标，不会被诱饵立即强制转移。死亡后立即禁用碰撞并从存活统计中排除。没有自动沉睡、回血、回出生点或噪声刷怪逻辑。普通怪音效不会发布声波事件。
