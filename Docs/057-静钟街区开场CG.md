# 静钟街区开场 CG

片长 18 秒，1280×720，24 fps，H.264 视频与 AAC 立体声。四幅原创分镜沿用奶蛙的深蓝短外套、黄铜耳罩、音叉和青色围巾。镜头推移、动态水波与声画剪辑表现静钟街区里的第一次惊醒。

| 时间 | 画面与声音 |
| --- | --- |
| 0–5 秒 | 推入静钟街区的旧站台。左右两侧错开的滴水声交代空间。 |
| 5–8 秒 | 奶蛙踩入浅水，声圈从落脚处扩张，音叉余音延伸到下一个镜头。 |
| 8–12 秒 | 钟壳虫从暗处显出红色眼缝，擦地与金属滑动声接在脚步之后。 |
| 12–18 秒 | 奶蛙穿过悬钟下的入口，片名浮现，共鸣音衰减。 |

## 文件与播放

成片位于 `Assets/StreamingAssets/EchoesBelow-Opening.mp4`，可独立播放。四幅分镜使用 ImageGen 绘制。水滴、脚步拟音、机械滑动与低频渐强取材于项目的 CombatAudio，素材来源见《054-战斗与探索音效》。音叉尾音为本片合成。

Unity 编辑器打开 `Assets/Echoes/Scenes/Opening.unity` 后点击 Play。构建入口顺序为 Opening、Prototype，播完进入第一层。空格或 Esc 可提前跳过，重新开始一局直接回到 Prototype。单独打开 Prototype 仍可直接调试战斗。

`OpeningCinematic.cs` 处理视频原比例显示、解码异常和场景切换。`PrototypeBuilder.cs` 在更新原型和构建时都保留片头入口。

## 验证与限制

PlayMode 用例 `OpeningCinematicTests.VideoDecodesAndEntersFirstFloor` 检查 Unity 取得有效解码画面，并在片尾自然切换到可玩的场景。外部播放器可检查四个镜头、字幕、音效和淡出。当前视频面向桌面版，其他平台的系统视频解码器需单独验收。
