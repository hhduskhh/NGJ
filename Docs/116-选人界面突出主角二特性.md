# 116 选人界面突出主角二特性

选人页采用一窄一宽两张原画卡。左侧以竖幅原画展示主角一；右侧在主角二的原画下说明移速转伤害、转换上限与开局取舍。两张卡都保留游戏内精灵，点击任意一张即可开始对应角色的游戏。

## 相关文件与配置

- `Assets/Echoes/Scripts/UI/TitleMenu.cs` 负责卡面布局与说明。主角二的转换比例和上限读取 Opening 场景所引用 GameConfig 的 runnerSpeedConversion 和 runnerMaxDamageBonus。
- `Assets/Echoes/Resources/SelectExplorer.png` 采用原始主角一设定图的竖幅取景。现有资源引用会自动使用新图。

## 验证与已知问题

在 Unity 编辑器运行 PlayMode 的 OpeningCinematicTests，检查返回标题、分别点击两张卡进入第一层，并查看 1600 × 900 截图。双角色编号、定位标题、三列初始数值和主角一说明均已从可见界面移除。其他分辨率本轮未单独截图。
