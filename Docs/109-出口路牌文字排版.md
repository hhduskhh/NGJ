# 出口路牌文字排版

第一关出口路牌的操作提示原先过长，末字换行后叠到下方说明。现在两条提示各占一行，牌面按较长一行的实际字宽展开，两侧各留 16 个画布单位。

## 相关文件与编辑器配置

`Assets/Echoes/Scripts/UI/GameHud.cs` 负责计算标牌宽度和排布文字。沿用原有字体、字号和文案，场景与 Inspector 无需配置。

## 验证方法与范围

运行 PlayMode 用例 `RuntimeSmokeTests.FirstFloorSignsFollowPlayerProximity`。用例加载第一关、接近出口，并检查两条文本各自只占一行且宽度足够。以下为默认种子下的出口截图局部。
