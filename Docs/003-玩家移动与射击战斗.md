# 003-玩家移动与射击战斗

- 功能：WASD 移动、鼠标瞄准、按住左键射击。子弹逐段 CircleCast，防止高速穿墙；敌我弹丸区分目标，墙壁阻挡弹丸。玩家受伤有短暂无敌与闪烁提示。
- 相关文件：`PlayerController.cs`、`Projectile.cs`、`GameConfig.cs`。
- 编辑器配置：模板原有 Input Manager，`activeInputHandler=0`，使用 Horizontal/Vertical 轴；俯视 Rigidbody2D 重力为零并冻结旋转，固定更新 60 Hz。
- 验证方法：沿墙移动；子弹撞墙消失；射击普通怪可使其追击并扣血；靠近敌人受伤，生命为零显示失败界面。
- 已知问题：只有一种基础枪械，无换弹、翻滚、弹药、背包或多武器系统；这些机制不在本次原型范围。正式操作手感需人工试玩调整。
