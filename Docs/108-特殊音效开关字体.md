# 108 特殊音效开关字体

开始菜单和暂停菜单的设置项统一命名为「特殊音效」。开启时全屏点亮播放大笑，关闭时播放钟鸣，沿用玩家已保存的选择。

## 相关文件与编辑器配置

`TitleMenu.cs` 和 `GameHud.Screens.cs` 定义两个菜单的文案。两处均使用 `Assets/Echoes/Resources/FusionPixelUI.asset`。修改文案后可在 Unity 编辑器执行 `Echoes > Bake Interface Font`，将新增汉字烘焙到同一套像素字图集。

## 验证

分别打开开始菜单和暂停菜单的设置页，切换「特殊音效」。检查名称和两种状态使用同一套像素字。也可在 FusionPixelUI 的 Character Table 中核对「特殊音效」「开」「关」「已开启」「已关闭」的全部字形。

## 已知问题

此字库采用静态图集，后续改名若引入新字，需再次烘焙。
