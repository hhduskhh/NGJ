# 107 全屏点亮大笑音效开关

开始菜单和局内暂停菜单的「设置」中都可以切换「全屏点亮大笑音效」。首次游戏默认开启。关闭后，下次按 F 成功释放技能会播放一段 1.15 秒的上行钟鸣。两个入口共用同一项 PlayerPrefs 偏好，重新启动游戏后沿用上次选择。

## 相关文件与编辑器配置

- `TitleMenu.cs` 和 `GameHud.Screens.cs` 提供开关。`NoiseSystem.cs` 在释放时选择音频片段。
- 普通音效为 `Assets/Echoes/Resources/CombatAudio/ScreenLightChime.wav`，由三个错开起音的钟音合成。大笑沿用同目录的 `ScreenLightLaugh.wav`。
- 两种声音共用 `DefaultGameConfig` 的 Screen Light Volume，以及游戏的暂停和全局静音设置。无需在场景中绑定新资源。

## 验证

- 在开始菜单关闭开关，开始游戏后按 F，确认听到上行钟鸣。按 Esc 进入设置，确认开关显示「已关闭」。
- 打开开关并继续探索，等冷却结束后再按 F，确认听到原大笑。重启游戏，检查开关状态。
- PlayMode 用例 `ScreenLightRevealsViewportAndRechargesInPlayTime` 检查成功释放时选中的音频、暂停和冷却限制，以及通过暂停设置切换后下一次释放的音频。

## 已知问题

自动测试检查播放状态与片段选择，和战斗声音混合时的听感需在游戏内试听。
