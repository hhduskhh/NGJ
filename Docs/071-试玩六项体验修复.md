# 071 试玩六项体验修复

依据 [070 试玩体验报告](070-试玩体验问题.md) 的六个优先问题调整。

| 项目 | 玩家体验与实现 |
| --- | --- |
| 掩体索敌 | 玩家和各武器筛选目标时按实际子弹半径查询物理弹道，优先最近且能命中的可见敌人。远程守卫在家具挡弹时会继续移动。涉及 `PlayerController`、`WeaponInventory` 的既有索敌入口、`EnemyController`、`DungeonMap` 和 `Projectile`。 |
| 出生路牌 | 每层出生点旁有一块像素木牌，箭头朝向起始房唯一出口。靠近显示 WASD 移动、左键射击及祭坛目标。路牌可穿行。精灵在 `Resources/Art/Common`，摆放和提示分别由 `DungeonMap` 和 `GameHud` 管理。[正常视野下的出生画面](Images/071-出生路牌.png) |
| 满级升级 | `UpgradeDefinition` 根据本局实际属性与当前武器过滤达到上限的选项。共振扩音器的两个效果都满后才退出。剩余有效选项少于三种时只显示可选卡，键盘快捷键与卡片数量一致。 |
| 换种重开 | 第一次开局读取场景配置的种子，点击「再来一局」会生成与上一局不同的种子。地图、商店、刷怪及升级使用新局配置。种子写入运行时副本。 |
| 随机商店 | 每层在普通房中随机选择一个摊位。生成器检查柜台前方、门口净空、陷阱距离、占地和放置后的可达性。每个种子可重现其摊位位置。靠近后仍按 E 进入。 |
| 未拾金币 | 守关者死亡时，先将本层剩余金币计入钱包，再打开下潜或最终结算。普通吸附与结算共用 `GoldPickup.Collect`，已入账的金币只结算一次。 |

## 编辑器配置与验证

直接运行 Opening 或 Prototype 场景。首局种子取自 DefaultGameConfig。木牌采用 Point 过滤、16 PPU，使用现有像素字体。需要更新字库时使用 Echoes 菜单的 Bake Interface Font。

Unity 2022.3.62f3c1 独立副本中，43 个不同的 PlayMode 用例通过。覆盖近敌被掩体挡住时改射远敌且实际造成伤害、六武器索敌、升级只剩两张卡、重开换种、击败守关者结清金币、六个种子的商店房间角色与路径、三层地图、商店交互和 HUD。另检查了 1600×900 正常视野的出生画面。随机生成验证为抽样，原生窗口键盘验收未在批处理模式下运行。
