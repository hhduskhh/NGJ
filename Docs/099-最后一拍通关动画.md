# 最后一拍 · 通关动画

击败第三层原音之心后，战场暂停，播放 15 秒的插画式尾声，随后淡入本局装备和统计。空格、回车、Esc 或单击可直接查看结算。片中使用合成音效，音量跟随游戏静音键 M。

| 时间 | 镜头 |
| --- | --- |
| 0–4 秒 | 奶蛙捧着原音核，背包敞开。镜头轻轻推近，最后一拍响起。 |
| 4–6 秒 | 切到工坊的活塞特写。固定机位停留两秒，扣环声接到机械落座的低响。 |
| 6–12 秒 | 旧站台的水洼边，奶蛙扶着耳罩，钟壳虫伏在暗处。画面停在这个瞬间，传来一声水滴。 |
| 12–15 秒 | 霜窗后是一盏暖灯，一只手贴着玻璃。镜头略微推近，淡出。 |

## 资源与配置

成片位于 `Assets/StreamingAssets/EchoesBelow-Ending.mp4`，H.264、1280×720、24 fps，音轨为 48 kHz 立体声 AAC。四幅静态插画沿用开场 CG 的角色与场景风格，以整幅轻推、切镜和声音串起归途。

`GameHud.Ending.cs` 在现有结算画布播放视频，按原比例适配窗口，播放期间暂停探索音乐。`GameHud.Feedback.cs` 处理跳过和结算淡入。资源通过 StreamingAssets 路径加载，无需在 Inspector 绑定。胜利面板的淡入时长沿用 GameConfig 的 victoryRevealSeconds。

## 验证与已知限制

在 PlayMode 运行 HudFeedbackTests 的 EndingDecodesAndReturnsToVictoryResult 和 RevealConsumesFirstPressAndReleaseBeforeDescent，检查视频解码到最后一个镜头后结算可用，以及跳过操作只展开结算。也可直接播放 MP4 审看四个镜头，或在 Prototype 场景击败第三层守关者验收。当前目标为 Windows 桌面，其他平台需验证本地视频解码。播放报错或连续八秒无解码进展时返回结算。
