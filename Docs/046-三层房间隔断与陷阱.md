# 三层房间隔断与陷阱

## 房间动线

| 房间 | 布局 |
| --- | --- |
| 出生房 | 补给柜台两侧各一段短墙。出生点到柜台保持畅通，房内安全。 |
| 单格房 | 两道错位横墙将中央陈设与两侧通道分开。 |
| 双格、三格长廊 | 沿长轴交替放置隔墙，三格房的墙段更长，玩家可从墙端绕行。 |
| 方形大厅 | 四段墙围出中央通行区，并保留外围路线。 |
| L 形房 | 按每格连接方向设置侧廊，引导玩家绕过拐角进入另一翼。 |
| Boss 房 | 两翼各设一段错位纵墙，陷阱分置左右，中央留作交战区。 |

隔墙使用当层墙砖，参与碰撞、寻路和视线判定。地图先布墙，再安排家具和陷阱。每个非出生格在两翼各寻找一块 3×3 的空地，分别放置地刺和炸弹。

## 陷阱与调参

- 地刺休眠 2 秒，闪烁预警 0.75 秒，然后升起 0.65 秒。半径 0.85 格，每次升起最多对玩家造成一次 10 点伤害。
- 炸弹在玩家进入 2.1 格范围且与炸弹之间视线畅通时点燃。1.1 秒后爆炸，仍在有效范围内的玩家受到 16 点伤害，离开可躲避。每枚炸弹只爆炸一次。
- 两种陷阱都使用玩家已有的闪避和受击无敌逻辑。暂停、升级和商店期间计时冻结。当前版本陷阱只影响玩家。
- 在 Inspector 中选择 `Assets/Echoes/Settings/DefaultGameConfig.asset`，展开 **Room traps** 可调伤害、半径与时间。

## 相关文件与验证

房型和落点在 `RoomInterior.cs`，地图接入在 `DungeonMap.cs`，计时和伤害在 `RoomTrap.cs`，参数在 `GameConfig.cs`。三张陷阱精灵位于 `Assets/Echoes/Resources/Art/Common`，由 `GameArt.cs` 加载。

在 Unity Test Runner 的 PlayMode 页运行 `RoomTrapTests`，覆盖三层房间墙体碰撞、陷阱数量、房间中心可达、炸弹命中与躲避、地刺伤害。多种子回归使用 `FloorGenerationTests.ManySeedsProduceConnectedWalkableFloors`。

Unity 2022.3.62f3c1 独立副本定向 PlayMode 测试 6 项全部通过，覆盖上述用例以及第二、三层场景物件、柜台和弹道回归。修正陷阱单图导入后，含三张 32×32 精灵尺寸断言的两个陷阱用例再次通过。

## 已知边界

布局在运行时生成。空地不足时会跳过对应陷阱。默认伤害和预警时间仍需人工试玩评估。
