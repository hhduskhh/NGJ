# 静钟街区背景音乐

进入第一层后，yd 的《EmptyCity》以独立的 2D 音源循环播放。换房和打开升级面板时音乐连续播放，下到第二层时停止。M 键同时控制音乐与音效。

## 文件与编辑器配置

- `Assets/Echoes/Resources/EmptyCity.ogg` 为原版 OGG，按 Streaming 导入。[作品页](https://opengameart.org/content/emptycity-background-music) · [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- `Assets/Echoes/Scripts/Core/RunController.cs` 管理播放。在 Prototype 场景的 RunController 上调整 Music Volume，默认值为 0.12。

## 验证与已知问题

`Assets/Echoes/Tests/PlayMode/CombatAudioTests.cs` 中的 `EmptyCityLoopsOnFirstFloorOnly` 已通过。测试从 Prototype 入口检查剪辑加载、循环开关、起始房与守关房的播放状态，以及进入第二层后的停止状态。

可在第一层走动、投掷响铃并按 M 切换静音，试听音乐与操作提示的相对响度。默认音量仍待实际设备试听确认。
