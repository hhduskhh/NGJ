# 063-世界观故事与 UI 氛围基调

## 定调

一句话：**这是一座把声音当作记忆的遗迹；拾音者必须一路制造声音，才能走到最需要安静的地方。**

本文是叙事与界面的共同基准，不是新增剧情系统。当前原型已有可跳过的开场 CG，没有对话或剧情分支。后续 UI 文案、标题、配色、图标、动效与环境叙事，以本文为准。

## 世界观短篇：最后一拍

共鸣城曾经不烧煤，也不点灯。

它靠一段被称作「原音」的声音活着。钟楼用它报时，管道用它送暖，工坊用它推动活塞；人们把要说的话寄存在钟舌、管壁和陶片里，等到想听的时候再取出来。城里的每一面墙，都记得自己听过什么。

后来，所有声音在同一刻叠在了一起。

史书把那一夜叫作「大共振」。没有人知道它从哪一声开始，也没有人知道它什么时候结束。共鸣城沉入地下，钟停在半途，活塞停在半程，最后一批居民的声音被折进墙体，像没有寄出的信。

很多年后，地表的人叫它「寂响遗迹」——从外面听，它安静得像一座空坟；走进去才会知道，那里不是没有声音，只是所有声音都还在等一个回答。

拾音者带着一只空的共振背包、一把调过音的枪和一副护耳下到遗迹。他要取回原音核，让地表的聚落再亮起一个冬天。可在这里，脚步声会惊醒沉睡的守卫，枪声会唤起旧日的巡逻，连呼吸都可能被墙壁记住。越多的回声醒来，背包里的力量越强；走得越深，他越像一个把死者重新叫醒的人。

第一层的钟还在等下班，第二层的机器还在等卸压，第三层的原音之心还在重复大共振前的最后一拍。

它们不是守着宝藏的怪物。它们只是还没有收到「可以停了」的指令。

拾音者必须一路制造声音，才能走到那个最需要安静的地方。

## 开场三行

可直接用于标题画面或首次下潜：

> 共鸣城不是被摧毁的。  
> 它只是停在了最后一个声音里。  
> 拾音者，下去把它听完。

## 三层的故事职能

| 层 | 曾经是什么 | 如今在做什么 | 守关者 | 叙事关键词 |
| --- | --- | --- | --- | --- |
| 静钟街区 | 生活与交通的外层街区 | 钟停在半途，巡逻仍在执行旧路线 | 守钟者 | 日常、停摆、等待下班 |
| 锈鸣工坊 | 把共振转成机械动力的工坊 | 机器反复执行旧班次，压力从未卸下 | 鼓压巨偶 | 过载、惯性、没有结束的轮班 |
| 原音圣所 | 城市声学技术的源头 | 核心封闭，设施异常整齐地维持最后一拍 | 原音之心 | 安静、完整、拒绝结束 |

三层不是三个独立的关卡，而是同一座城市从**生活**到**运转**再到**源头**的三层剖面。

## 核心设定

- **原音**：共鸣城共同维持的一段秩序。它既是能源，也是记忆的载体；不是魔法，更不是许愿机。
- **大共振**：让所有声音叠在同一刻的事故。原因不解释，不设一个明确的幕后反派。
- **回声**：被留在物体和空间里的声音残响。敌人不是亡魂，而是被回声驱动、仍在执行旧指令的器具。
- **拾音者**：下潜者、回收者，不是来屠城的英雄。护耳、青围巾和共振背包是他的识别轮廓。
- **共振背包**：把附近被惊醒的回声转成力量。玩法上的「围攻加成」在叙事上就是「回声压强」。
- **守关者**：旧日协议的守卫，不是邪恶首领。它们挡住去路，是因为还没有收到停止指令。
- **共鸣币**：以音叉为形的旧城配给凭证；商店是仍在运转的无人补给站。
- **回声重排**：每次下潜，遗迹的空间会重新排列。像一段被反复讲述的记忆，每次都会走样；这为随机房间提供叙事解释。

## 主题与叙事边界

- 核心母题：**声音是记忆，战斗是打扰，力量来自被惊醒的过去。**
- 情绪基调：**哀而不伤，冷而不恐。** 遗迹有悲伤，但不是恐怖游戏；不出现血腥、尸体堆和尖叫式惊吓。
- 敌人以机械、陶壳、晶体和旧器具为主，不把普通怪写成无辜者的处刑。玩家是在让失控的旧程序停下，而不是屠杀居民。
- 原音核被取走后的代价保持暧昧：地表会因此得救，遗迹可能会真正沉默。这个取舍不做成系统选择，玩家的下潜本身就是回答。
- 不解释大共振的完整真相，不设置全知旁白，不用大段文字倒叙。世界观只通过短句、命名、环境细节和守关者的行为露出来。
- 允许安静和留白。不要把所有东西都强行解释成声学设定；氛围比设定集重要。

## UI 氛围总纲

整体 UI 应该像**一台被拾音者从废墟里捡出来、重新接上电的旧式听音仪**：暗色玻璃、氧化黄铜、青色刻度、琥珀信号灯。它冷静、克制、略带旧伤，不像现代游戏 HUD，也不像魔法羊皮纸。

| 维度 | 基准 | 避免 |
| --- | --- | --- |
| 形态 | 仪表、刻度、线路图、旧式机箱、双线边框、铆钉与铭牌 | 全息投影、圆角卡片堆叠、羊皮纸卷轴、手写花体 |
| 材质 | 烟熏玻璃、失光黄铜、暗色搪瓷、轻微磨损 | 高亮塑料、镜面金属、霓虹渐变 |
| 布局 | HUD 四角锚定；信息像仪器读数一样稳定 | 满屏悬浮窗、频繁跳位、遮挡战斗 |
| 信息层级 | 功能信息高对比、可读；氛围信息压低、可忽略 | 为氛围牺牲数值清晰度 |
| 动态 | 指针轻摆、信号灯呼吸、继电器式短促切换 | 全屏故障闪烁、弹跳缩放、持续扫光 |
| 声音 | 轻铃、阻尼按键、低沉稳压、纸带继电器声 | 现代电子提示音、尖锐警报、纯音效传递关键信息 |

**可读性优先于世界观。** 功能名不够清楚时，保留「商店」「金币」「升级」这类直白词，把氛围放进副标题、美术、图标和动效里，不要让玩家先解谜再理解界面。

## 色彩与符号

| 色彩 | 语义 | 用法 |
| --- | --- | --- |
| 墨蓝 / 暗蓝灰 | 遗迹、夜色、仪器底板 | 面板、背景、未探索区域 |
| 黄铜 / 琥珀 | 价值、留存、旧城 | 金币、重要数值、标题强调 |
| 青色 | 听觉、共振、可交互 | 交互提示、视野声圈、确认状态 |
| 珊瑚红 | 危险、敌意、过载 | 敌人警戒、Boss、伤害与风险升级 |
| 象牙白 | 圣所、封存、高等级 | 第三层建筑、稀有品质与圣所界面 |

四档品质可以读作四种频段：

- **白 Ⅰ**＝基准音
- **蓝 Ⅱ**＝泛音
- **紫 Ⅲ**＝共鸣
- **红 Ⅳ**＝过载

红色同时承担危险语义，因此商店的红色品质必须同时显示品质数字与文字，不能只靠颜色区分。

常用符号保持简单：

- 音叉＝货币、调音、核心
- 钟＝街区、守关者、旧协议
- 活塞 / 压力表＝工坊与过载
- 晶体 / 音叉臂＝圣所与高等级
- 声圈 / 刻度环＝听觉范围与共振状态

## 字体与文案

- 使用当前 Fusion Pixel 简中点阵字体，保证中文可读性，不引入书法体。
- 标题可用拉开字距的处理，例如「寂 响 遗 迹」「本 层 已 净 化」，像仪器铭牌；正文保持正常字距。
- 数字与状态保持稳定对齐，避免数值跳动时界面抖动。
- 文案语气：**短、冷、礼貌，像仪器注释**。少用形容词，不用感叹号，不玩网络梗。
- 教程可以直白，叙事文案尽量克制。称呼玩家为「你」，称呼角色为「拾音者」。
- 避免在界面里直接写 Boss、Buff、刷怪、DPS 等开发/玩家黑话；用「守关者」「共振」「回声」「下潜」「补给」等功能与世界观兼容的词。
- 不要把所有按钮都写成诗句。按钮首先是按钮。

## 各界面落点

| 界面 | 氛围方向 | 文案建议 |
| --- | --- | --- |
| 标题 / 主菜单 | 一块被重新点亮的旧仪器铭牌；安静、留黑 | 主标题「寂响遗迹」；副标可用「在无人回应的城市里，制造最后一声回响」 |
| 主 HUD | 生命、共振、回声压强像三组稳定读数 | 「躁动 → 力量」可保留；副标注明「被惊醒的回声正在供能」 |
| 5×5 小地图 | 一张旧城听音图，不是现代雷达 | 未探索＝未听见；已探索＝已记录；起点「起」、终点「终」保留 |
| 共振升级 | 三张调音方案卡片；风险升级像被红笔圈出的过载档 | 「调音 / 选择一段共振」；风险项标「过载」 |
| 补给商店 | 无人值守的旧配给站，货架和面板仍亮着 | 功能仍叫「商店 / 金币」；副标可写「配给站仍在运转」 |
| 守关者血条 | 旧仪表上的单行警戒读数，不铺满屏幕 | 「守 关 者 / 名字」；可加一句极短的守关者注释 |
| 层间过渡 | 老式升降台与逐渐变化的材质 | 「下一层还醒着」 |
| 层完成 | 仪器归零、余响渐弱 | 「本层回声已平息」 |
| 最终胜利 | 核心稳定，城市终于获得一次结束 | 「原音归位。城市终于可以安静。」 |
| 失败 / 暂停 | 不嘲讽、不喧闹；像录音被轻轻按下暂停 | 失败可用「你的声音被遗迹收下了」；暂停仍用「暂停探索」 |

## 实施边界与验收

本文只确立叙事与 UI 氛围，不新增玩法、对白、过场、可拾取文本或剧情选择。现有界面继续按当前版本运行；后续改 UI 时再逐项引用本文。

后续界面验收时检查：

1. 它看起来像旧式听音仪，而不是现代科幻 HUD、奇幻羊皮纸或通用手游面板吗？
2. 五种语义色是否只承担各自职责？红色是否没有被拿去做普通装饰？
3. 功能信息是否仍然清楚，氛围是否没有盖过数值和操作？
4. 文案是否短、冷、可读，并且没有引入「古代邪恶」「天选英雄」这类与遗迹基调冲突的叙事？
5. 界面是否留出了安静和空白，而不是用光效和装饰把每一处填满？
6. 新加的名称、图标、文案，能否在 `012-三层美术风格设计`、`033-房间障碍与装饰扩展报告`、`034-房间生成美术需求清单` 之间保持一致？

相关参考：`012-三层美术风格设计`（三层材料与敌人轮廓）、`026-正式美术素材导入与配置`（现有商店 UI 素材）、`032-房间生成与三层地牢`（当前流程）。
