# 围攻蓝圈随枪声和视野变化

围攻半径取已装备武器的最大实际枪声半径与玩家当前周身照明半径的较小值。玩家静止时使用基础渐变视野，声波扩张或回缩会改变周身照明。偏离玩家的声波只贡献仍能覆盖玩家周围整圈的部分。全屏点亮按波前到达的范围和镜头边缘计算。狭窄弹道只照亮局部。

DungeonVisibility 计算半径，RunController 将同一个值交给 PlayerController 绘制蓝圈，并用它统计范围内存活、清醒且实际可见的敌人。蓝圈标示距离边界；地形遮挡仍通过敌人位置的可见性判断。枪声和视野继续使用 DefaultGameConfig 与武器的现有设置。

PlayMode 用例 HearingAndVisionPulseTests.PressureRingAndBonusFollowCurrentLightAndGunNoiseCap 检查静止、声波照亮与消失时，圈的大小是否和围攻人数同步。手动验证可在开阔处静止后连续射击，观察蓝圈扩张到枪声上限，再随照明收缩。
