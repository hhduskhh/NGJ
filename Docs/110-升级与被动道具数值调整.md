# 升级与被动道具数值调整

按本轮数值表调整四项升级、两项被动道具，其他数值沿用原配置。

| 项目 | 当前效果 | 叠加与上限 |
| --- | --- | --- |
| 快装枪机 | 每次射击间隔乘 0.8 | 两次为原来的 64%，最短 0.05 秒 |
| 轻装行进 | 每次基础移速加成 +15% | 最终移速最高为基础的 250%；基础移速 9 时最高 22.5 单位/秒 |
| 共振扩音器 | 公共枪声半径 +5，每敌围攻增伤 +3 个百分点 | 公共半径最高 12，每敌增伤最高 20% |
| 致命打击 | 暴击伤害倍率 +0.10 | 按原有加法叠加，初始 ×2.00 升至 ×2.10，最高 ×5.00 |
| 消声套管 | 枪声半径 -1、伤害 +10%、攻速 -3% | 蓝阶，36 金币，最多 2 件 |
| 疾行发电机 | 移速 +8%、生命上限 -12；每 1% 永久净移速加成转为 0.8% 伤害 | 转换最多 +24%；紫阶，60 金币，最多 1 件 |

疾行发电机单独购买时提供 6.4% 转换伤害；永久净移速加成达到 30% 时，转换伤害达到 24% 上限。升级移速仍与道具移速加法叠加。

## 相关文件与编辑器配置

- `Assets/Echoes/Scripts/Progression/UpgradeDefinition.cs`：升级效果、说明及满属性后的候选过滤。
- `Assets/Echoes/Scripts/Combat/PlayerController.cs`：实际移动速度上限。
- `Assets/Echoes/Scripts/UI/GameHud.Backpack.cs`：背包移动速度显示上限。
- `Assets/Echoes/Scripts/Progression/ShopCatalog.cs`：被动道具数值与说明。
- `Assets/Echoes/Scripts/Progression/PassiveInventory.cs`：疾行发电机转换系数。

默认配置沿用代码中的武器和道具定义，场景与 Inspector 无需额外配置。

## 验证方法与已知问题

针对性 PlayMode 用例：`VisibilityAndUpgradeTests.ExhaustedUpgradesLeaveOnlyUsefulCards`、`VisibilityAndUpgradeTests.EightUpgradesApplyToCombatAndLoot`、`ShopTests.PurplePurchasesConvertSpeedAndRepairEverySixKills`。分别检查新移速上限的候选过滤、升级叠加与封顶、道具转换及回血。

Unity 2022.3.62f3c1 批处理运行以上 3 项用例，全部通过。测试报告为本地 `TestResults/balance-110-playmode.xml`，不纳入版本管理。

“暴击伤害提升 10%”沿用原有倍率加法口径，表示倍率增加 0.10。快装枪机两次叠加按 0.8 × 0.8 = 0.64 计算。
