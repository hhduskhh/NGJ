# 二层守关者长冲撞与三层弹幕降频

第二关守关者锁定起冲时的玩家方向，在空地上用 0.8 秒冲过 18 个世界单位，即一个 36 单位宽房间的一半。起冲间隔仍为 1.4 秒。墙和实体障碍会限制实际位移。

第三关弹幕发射频率乘以 0.7，每轮 18 发，完整周期从 0.6 秒延长至约 0.86 秒，蓄力音效与新周期同步。第三关冲刺和召唤继续独立计时。

在 `Assets/Echoes/Settings/DefaultGameConfig.asset` 的 Gatekeeper 区域调整 `secondBossDashRoomFraction`、`secondBossDashDuration` 与 `finalBossBarrageRateScale`。默认值在 `GameConfig.cs`，出招和物理移动在 `EnemyController.cs`。

在 PlayMode 运行 `EnemyRoleTests.SecondBossDashesHalfARoomOnClearGround` 测量实际位移，运行 `BossUsesFloorHealthAndAttackPatterns` 检查三关出招时间与每轮弹数。
