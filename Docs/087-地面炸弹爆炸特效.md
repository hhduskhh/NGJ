# 地面炸弹爆炸特效

地面炸弹引信结束时，中心闪光与金红色冲击环同时出现。冲击环向外扩散至伤害半径后淡出。玩家及时撤离也能在原地看到爆炸，切换楼层会随房间清理特效。

在 DefaultGameConfig 的 Room traps 中调整 Bomb Radius 和 Bomb Flash Seconds，特效默认持续 0.4 秒。RoomTrap 在引爆时创建 BombExplosion，中心闪光复用 Common/effects 像素帧。无需放置预制体。

PlayMode 用例 RoomTrapTests.BombCanBeEvadedAndSpikesDamageAStationaryPlayer 检查撤离、受击、特效生成与销毁。可在游戏里踩入警告圈并撤出，观察扩散和淡出。特效受地牢黑暗遮罩影响。
