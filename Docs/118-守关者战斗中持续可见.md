# 守关者战斗中持续可见

三关守关者从激活到被击败期间，本体精灵绘制在黑暗遮罩上方，移动、蓄力和受击时都可辨认。弹丸和冲刺方向箭头绘制在本体上方。该效果只作用于本体，周围地面和召唤物继续使用场景光照。

`Assets/Echoes/Scripts/Presentation/GameArt.cs` 按守关者状态选择绘制顺序，`Assets/Echoes/Scripts/Visibility/DungeonVisibility.cs` 定义遮罩、守关者和危险提示的相对顺序。无需配置场景或材质。

在 PlayMode 运行 `EnemyRoleTests.ActiveBossRendersAboveDarknessOnEveryFloor`，验证三关在沉睡、激活和死亡时的绘制顺序，并查看第一关的黑暗场景截图。此效果在摄像机范围内生效，自动瞄准继续使用现有的照明、视线和弹道判定。
